## 目录与常用命令

| 路径 | 用途 |
| --- | --- |
| `server.py` | 启动入口，转到 `backend/server.py` |
| `backend/` | Python 服务、业务模块、初始化与空间分析 |
| `index.html`、`app.js`、`style.css` | 页面入口与全局脚本、样式 |
| `frontend/` | 前端业务模块及地图依赖 |
| `assets/` | 地图数据、图片和预览素材 |
| `scripts/` | 地图构建、数据导入和测试运行脚本 |
| `test/` | Python / JavaScript 测试和浏览器验收脚本 |
| `reports/` | 验收 JSON 结果与 `screenshots/` 截图 |
| `docs/` | 历史验证记录 |
| `data/` | 本地运行数据（不纳入 Git） |

以下命令在仓库根目录运行：

```sh
prototype/.venv/bin/python prototype/server.py --port 5190
prototype/.venv/bin/python prototype/scripts/test.py
npm --prefix prototype test
npm --prefix prototype run build:map
```

后端沿用同级模块导入；测试运行器会设置模块路径。单独运行某个后端测试时，可在 `prototype/` 下执行 `PYTHONPATH=backend .venv/bin/python -m unittest discover -s test -p 'test_centers.py'`。
浏览器验收脚本位于 `test/check_*.py`，请通过 `DEMO_QA_URL` 指向使用独立数据库启动的服务；本地验收结果统一写入 `reports/`，部分专项脚本仍写入 `/tmp/`。

## 地图引擎

地图场景已使用 **OpenLayers 10.10.0**，支持缩放、拖动、区域定位、授权图层开关、图斑查询和多边形近似量算。图层开关保留当前视图；离开场景时释放地图实例。

底图和行政区数据复用项目根目录的 `内蒙古一张图demo/`：天地图影像、矢量、地形及各自注记，保持国界图层叠加；同时提供自治区界、12 个盟市界和 103 个旗县界开关。在线瓦片无法加载时回退到 demo 本地行政区底图。在线底图使用原 demo 浏览器 Key；底图是否可用取决于网络和服务端授权。

原 demo 地图引擎是 Leaflet，本原型按已确认选型使用 OpenLayers 承载相同地图资源。渲染视图为 EPSG:3857；场景输入继续使用 EPSG:4490，经纬度投影仅用于演示显示。原 demo 将行政区数据标注为 GCJ-02，导入时进行近似逆偏移后叠加天地图，不沿用其“天地图等于 GCJ-02”的错误假设。正式数据仍需核验源坐标系与转换精度。图斑为虚构数据，量算采用球面近似，不能作为业务精确面积。

OpenLayers 的 JavaScript、CSS 和许可证已打包在 `frontend/vendor/`，Python 启动和浏览器访问不依赖 CDN，也无需现场安装 Node。仅修改依赖或地图打包入口时需要重新构建：

```sh
cd /Users/mac/oneMap/prototype
npm ci
npm run build:map
```

需要重新导入 demo 地图配置与边界时，在项目根目录运行 `python3 prototype/scripts/import-demo-map.py`；原 demo 保持原样。

浏览器回归使用独立数据库服务：`DEMO_QA_URL=http://<本机局域网 IP>:5198 python3 prototype/test/check_map_browser.py`。该脚本验证场景加载、图层和权限过滤、视图保留、图斑点击、绘制量算及移动布局。

## 推荐演示脚本

1. **元数据驱动检索**：后台编辑 `r1` 的某个字段，添加独有同义词并启用“AI 查询”，发布后在前台检索；关闭该字段查询标志再次发布，该字段同义词不再参与召回。“显示字段”独立控制详情展示。
2. **模板与关系**：资源配置中选择元数据模板，点击“应用所选模板字段”；按字段名合并并保留已有内容。填写 `表关联|r2|region_code|region_code`，保存时校验关系字段。
3. **知识生产**：知识库点击“导入文档”，选择多个 TXT/Markdown 文件，设置来源、标签、切片长度。结果逐项显示成功或失败、去重数量和处理节点。检查草稿后发布；前台政策助手返回相关片段及引用版本。
4. **实体网络**：文档配置中维护 `标识|名称|类型` 和 `起点标识|关系名称|终点标识`，预览图形后保存；列表“图谱”查看网络。
5. **动态指标**：编辑 `r2` 的示例 CSV 数据并发布；`年度耕地面积`、`耕地保护目标` 使用 `area`、`target` 字段，`耕地保护达标指数` 使用 `i_area / i_target * 100`。在“趋势对比”中计算两个年度和两个区域。
6. **协同执行**：广场选择“耕地保护协同助手”，提问“分析耕地保护”，查看资源、政策引用、指标及子智能体追踪。后台移除检索节点发布后，不再产生该节点的资源结果。
7. **提示词联动**：修改“资源检索意图识别”的“规则回答模板”，例如 `本次命中 {{count}} 项：{{resources}}`；发布后提问“地灾巡查”，回答使用新模板。提示词正文记录在执行输入，输出模板实际控制规则回答。
8. **质量回归**：语料问答样例中填写预期答案片段、资源集合及步骤序列，点击“评测与回归”。对比当前草稿与已发布资产，展开失败原因和实际输出。测试样例不参加该轮回答，防止标准答案泄漏导致虚假通过。可导出 JSONL 用于后续训练数据准备。
9. **NL2SQL / NL2API 演示**：SQL 模板使用命名参数，例如 `SELECT SUM(area) AS total_area FROM demo_cropland WHERE region = :region`；API 模板使用 `resources.search` 和 `question,region` 参数。试运行会实际查询本地授权示例数据，智能体“执行语料模板”节点可调用绑定模板。
10. **任务接力**：提问“包头市地灾”，点击“接续历史任务”，在新会话接续原有区域、主题和时间；明确指定新区域时覆盖旧条件。个人中心可调整技能等级、摘要和回答详略。
11. **反馈反哺**：后台反馈可转问答样例，也可创建元数据同义词或用户摘要的改进草稿；人工确认后应用。元数据仍需发布才影响检索。
12. **对话内申请**：回答点击“申请本次结果”，填写用途和期限提交，保留当前会话。后台逐项办理后授权状态同步前台。

## 能力接口

`POST /api/v1/agents/invoke`，JSON 内容类型，使用 `X-Demo-User: u1` 选择演示身份。

```json
{"apiVersion":"v1","agentId":"a1","question":"地灾巡查"}
```

可选 `sessionId` 继续原会话，或 `resumeFrom` 接续已有任务。返回 `apiVersion`、`sessionId`、`traceId`、`message`（回答、资源、引用、指标和执行追踪）。后台“调用与反馈 → 能力接口”可查看契约并试调用。

## 实现边界

- 所有业务数据、账号和地理范围均为虚构演示素材。身份可以直接切换，服务默认监听所有 IPv4 网络接口，未接入生产认证。
- 检索使用关键词、元数据同义词、字典和本地字符二元特征向量；不包含大模型语义推理或外部向量服务。知识处理同步执行，批次保留逐项结果，失败文件重新导入。
- 图谱是可编辑实体和关系网络，不包含图数据库和自动实体抽取。
- 指标真实计算本地 CSV；表达式支持已发布指标、数字、括号、加减乘除。依赖深度最多 8 层，拒绝循环、除零和越权。未连接生产数据库。
- SQL 在临时 SQLite 中对授权示例表执行单条只读 SELECT，结果最多 100 行。API 调用限定本地资源检索。自然语言到任意 SQL/API 的自动生成仍需模型接入。
- 编排按列表顺序执行，可调用知识/指标智能体并传递上下文；有循环与深度保护，不包含复杂分支、循环调度或分布式任务平台。
- 多轮摘要通过规则提取最近问题、条件、涉及资源与指标，最多保留 10 个任务摘要；不是大模型生成的语义压缩。
- 评测使用答案片段、资源集合、步骤顺序判定；不包含模型裁判和实际微调训练，JSONL 导出覆盖训练数据准备。
- 地图使用 OpenLayers，复用 demo 天地图底图与本地行政区数据；业务工具、专题图斑和资源中心审批仍为本地演示，真实业务空间服务待接入。

### 一张图内嵌 AI 地图助手（2026-09-16）

入口：`/#/admin/integration-results` → 地图上方「✦ AI 助手」。需要成果查看及空间分析权限。

已实现业务问题 → 受约束查询计划 → 参数化只读 SQLite SQL → 独立地图图层与表格；支持地区、年份、登记面积、审批状态、高风险等级、分组统计、追问、选区相交与周边距离。示例：

- `查询呼和浩特市的永久基本农田` → `按旗县统计`
- 新对话：`查询2025年面积超过20亩的建设用地` → `只看未审批的`
- 地图或结果表选中对象 →「使用选中对象」→ `查询周边1公里的建设用地`

每页 100 条，统计基于全量匹配结果；最多保留 5 个前端结果图层、每人 50 条服务端记录。历史恢复、分页、下载本页均重新检查权限和数据指纹，源数据变化后需重新查询。切换地图场景会清除前端助手状态。手机绘制时面板缩成底部提示条，关闭助手会取消绘制。停止等待仅阻止迟到结果上图，并在返回后取消该记录，不会中断已经发出的模型 HTTP 请求。

默认是明确标识的**本地业务解析**，未连接大模型，也未连接生产数据库。当前使用服务端授权地图的示例要素，建设用地示例为点；不能将其当作真实地块边界。面积按登记属性汇总（亩 / 公顷 / 平方米统一到公顷），没有裁剪、去重或跨表关联。分组统计展示数值及匹配对象，尚未制作行政区分级设色图。“新增”“违法”“合规”等问题需要业务口径，当前提示澄清或使用已有核查工具。

如需接入模型，在启动服务前设置后端环境变量 `MAP_AI_PLANNER_URL`，可选 `MAP_AI_PLANNER_TOKEN`（Bearer）。URL 要求 HTTPS，或本机 localhost / 127.0.0.1 HTTP。这是自定义 JSON 规划网关协议，不能直接填写聊天模型 completions 地址。网关接收：

```json
{"question":"查询2025年的建设用地","schema":{"fields":{},"layers":[],"enums":{},"groupBy":[],"operators":[],"sort":[],"schemaVersion":1},"previousPlan":null,"instruction":"只返回查询计划 JSON"}
```

实际 `schema` 由服务端填充授权图层、可用枚举、字段及操作符；不发送完整要素数据。网关应返回 JSON 对象（不要包 Markdown / choices）：

```json
{"filters":[{"field":"layer_id","op":"in","value":["nmg:construction"]},{"field":"year","op":"eq","value":2025}],"groupBy":"","sort":"name"}
```

不明确时返回 `{"clarification":"请明确查询年份"}`。字段及操作符必须取自请求 schema；支持 `eq/in/gt/gte/lt/lte/contains`，分组为 `region/county/layer_name/approval`，排序为 `name/area_desc`。网关不能返回 SQL、脚本或任意数据源地址。规划服务 8 秒超时，失败明确报错，不会静默切回规则解析；调用期间不持有全局状态锁，保存前重新校验权限和数据指纹。

验证：`cd prototype && PYTHONPATH=backend .venv/bin/python -m unittest discover -s test`。页面验收脚本 `check_map_ai_browser.py` 使用 agent-browser，`DEMO_QA_URL` 必须指向独立 QA 数据库。

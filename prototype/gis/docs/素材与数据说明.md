# 素材与数据说明

- 地图引擎：Leaflet 1.9.4，从用户提供的 TokenGIS/map-html-skill 包内复用；许可见 `assets/vendor/leaflet/LICENSE.md`，对应上游 https://github.com/Leaflet/Leaflet/blob/v1.9.4/LICENSE 。保持库版权头和地图署名。
- 风景图片：复用原 oneMap 中已标记许可的五张 Wikimedia Commons 图片，逐图来源与许可见 `assets/photos/credits.html` 和 `credits.json`。图片未被描述为本项目调查成果。
- 业务几何和属性：复用原 oneMap 的 `frontend/demo-map-data.js` 及 `assets/nmg-demo/data/runtime.json`，28 个图层，1,176 个模拟对象。源为 Point 的矿业权等保持点几何。登记面积沿用源属性，与几何面积分开。
- 行政区参考边界：沿用原有省域、12 个盟市、103 个旗县及城市标注数据。不是新增审核地图或测绘成果。
- 地形：来自原 demo 的 `nmg_dem_z7.npz` 本地缓存。源范围参照原 `build.log`（97°—126.1°E，37°—53.5°N），按墨卡托纬度重采样后生成地形晕渲，并按省域轮廓裁切显示。正式发布须核验原始数据许可、地图审图与精度；本次未将缓存称为生产底图。
- 依赖、图片和几何均随项目保存；新版地图运行时无需外部底图服务、API Key 或 CDN。
- 用户提供的可研 PDF、TokenGIS 技能压缩包和原始 DEM 未放入本次 Git 提交；文档保留资料名称与功能编号以便追溯。

# AI 空间助手原型

更新：2026-09-18。

## 访问与演示

启动 `prototype/.venv/bin/python prototype/server.py --host 127.0.0.1 --port 5190`，打开 `http://127.0.0.1:5190/gis/index.html#ai`。纯静态页面没有 SQL 服务；图层控制、量算和本地业务表单仍可使用。

首次演示在助手上方明确选择“演示管理员”。业务用户沿用后端授权，没有分析权限时显示提示，不自动切换身份。身份选择仅适用于本机原型的既有 X-Demo-User 机制。

## 三分钟演示脚本

1. 点击“查询基本农田”：呼和浩特市的永久基本农田返回4个对象，登记面积合计145150公顷，紫色结果上图。
2. 输入“只看面积超过100亩的”：展示追加的面积筛选条件。示例地块登记面积较大，本条件仍返回4个；可用“只看面积超过40000公顷的”展示收敛到1个对象。
3. 新会话后再次查询基本农田，再输入“按旗县统计”：显示4组数量、面积和条形图。展开查询依据查看实际执行SQL与绑定参数。
4. 滚动到明细，点击一个对象，输入“查询选中对象周边10公里的地质灾害隐患点”：执行空间缓冲查询并展示范围。部分对象周边没有隐患示例点，0结果也是实际结果，不预填虚构数据。
5. 输入“创建核查任务”：打开当前对象的预填表单，关联本轮空间范围，由用户填写说明后保存。
6. 使用“新会话”，输入“查询建设用地按旗县统计”：展示跨地区分组结果。

## 两种模式

- 演示规则模式：明确使用本地规则产生查询计划，后端真实执行参数化SQL、空间相交和统计，不调用模型。
- AI模型模式：通过已有模型规划网关理解问题。配置 `MAP_AI_PLANNER_URL`，必要时配置 `MAP_AI_PLANNER_TOKEN`，重启服务。未配置时明确报错，并提供切换演示模式按钮，不暗中降级。

规划网关是自定义JSON接口，不是直接填写模型厂商的聊天补全地址。它接收 `question`、`schema`、`previousPlan`、`instruction`，返回如下查询计划（或 `{"clarification":"请补充……"}`）：

```json
{"filters":[{"field":"region","op":"eq","value":"呼和浩特市"}],"groupBy":"county","sort":"name"}
```

网关负责适配所选模型，输出必须符合后端允许的字段及操作符。模型不直接生成可执行SQL。当前结果摘要由后端根据真实数据生成，不宣称模型已经生成专业研判。

## 实现范围

- GIS助手调用 `integration.ai.ask/result`，复用既有 `nmg-reference-demo` 数据与权限校验。
- 查询条件、执行状态、指标卡、分组条形图、分页表格、独立地图图层、空间范围、JSON本页导出和SQL依据。
- 连续追问继承查询计划与空间范围；地图区域、图层、选中对象或业务场景变化后开启新查询上下文。
- 停止等待、新会话或切换身份后不加载过期响应。新会话保留已有地图结果；切换身份清除助手结果图层。
- 当前页最多100个对象；总数和统计来自完整匹配结果。登记面积为属性求和，不是空间裁剪面积。
- 查询过程中只显示实际请求状态；完成后显示已完成步骤，不伪造逐步模型思考。
- 大模型密钥不在前端保存。未配置真实网关时只能验证演示模式和模型错误路径。

## 资源检索与对话式申请（2026-09-18）

打开 GIS 智能助手，可直接输入以下问题，也可使用欢迎区快捷按钮：

| 场景 | 输入 | 对话结果与后续动作 |
| --- | --- | --- |
| 业务表检索 | 找最近的地灾巡查记录表 | 展示资源类型、核心字段、坐标系设计口径、更新频次；按时间倒序导出 3 条虚构巡查记录 |
| 工具推荐 | 推荐合适的耕地监测工具 | 推荐卫片比对、地块外业核查两项服务；支持单项或一揽子申请 |
| 图层检索 | 调出某盟市永久基本农田图层 | 未明确区域时追问盟市；展示元信息，预览本地地图，发起申请 |
| 无匹配 | 查询 2000 年海洋保护区现场照片 | 明确提示无匹配，建议调整条件，不生成假资源或查询结果 |
| 资源申请 | 点击卡片中的“一键发起资源使用申请” | 在助手内填写用途、范围和期限，核对后显式确认提交或取消 |
| SQL 问数 | 查询呼和浩特市的永久基本农田 | 展示业务表元信息，执行实际本地参数化 SQL，输出数量、面积、数据表、地图和导出入口 |

### 对话内申请全过程

1. 申请草稿：列出申请资源，填写至少 4 字的具体用途，选择行政区范围和 7 / 30 / 90 天期限。
2. 确认阶段：展示完整申请摘要，提供“确认提交”“修改信息”“取消”。也支持直接输入“确认提交”“修改信息”“取消”。
3. 提交完成：返回申请编号和“待审核”状态。重复点击旧确认按钮不会重复创建申请。
4. 查询进度：输入“我的申请”或“查看申请进度”；也可从资源中心或工作台的资源使用申请入口查看同一记录。
5. 待审核：可撤回。原型审核需在助手上方显式切换为“演示管理员”，再输入“我的申请”。
6. 审核通过：显示有效期，按申请范围下载示例数据，或打开工具演示入口。
7. 审核退回：管理员填写至少 4 字的退回原因；申请人按意见修改后重新申请，保留原申请记录。
8. 授权到期：停止取用入口，提示重新申请；下载动作也再次校验状态和期限。

### 演示边界

- 目录元数据、巡查记录及审批流为原型示例。申请保存在当前浏览器，未连接生产资源中心或真实审批系统。
- 示例坐标系标注 CGCS2000 是资源目录设计口径；现有地图几何沿用项目已有示例数据，不承诺真实测绘精度。
- 卫片工具入口连接现有图层卷帘演示，外业工具入口连接范围查询与核查任务。自动卫片变化识别、移动采集需后续服务接入。
- SQL 展示实际执行的 map_features 表及参数。用户示例中的 basic_farmland.city_name 是目标业务库的示意命名，当前没有虚构该物理表或执行结果。
- 业务用户没有问数权限时，助手明确提示权限不足；可显式切换演示管理员验证 SQL 场景。模型模式仍需要配置模型服务。

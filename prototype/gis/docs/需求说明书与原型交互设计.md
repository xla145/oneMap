# 内蒙古自然资源“一张图”系统 Demo 升级需求说明书

版本：V2.0 交互原型版
日期：2026-09-17
最终项目：oneMap
交付对象：业务负责人、产品设计、开发与演示人员

## 1. 建设目标与依据

本轮把空间地图作为日常业务操作的主体。用户从行政区、专题图层、业务对象或任务进入，在同一工作空间完成资源发现、空间查询、对象核查和演示任务办理。对外介绍采用自然风光、大标题与连续叙事，突出内蒙古自然资源与空间科技的结合；内部业务端采用目录、工具、属性和表格，减少需要反复跳转的卡片入口。

### 1.1 输入材料

|材料|本轮使用方式|证据范围|
|---|---|---|
|一张图功能思维导图.md|全量编号解析、第一二部分信息架构重组、第三部分五场景主线设计|原文件 796 行；保留原编号及重复编号，不擅自纠正文档的需求归属|

### 1.2 产品决策

1. 默认进入“自然资源一张图”，保留整个地图状态；查看资源、工具、对象和任务主要使用右侧面板。
2. 公众门户单独组织介绍与服务导航，不把宣传页面的卡片布局迁移到业务工作台。
3. 资源目录中的卡片需求按用户本次指令调整为目录树与紧凑列表，保持元数据、预览、申请等信息完整。
4. 五个业务场景使用各自相关图层和办理路径。场景共用底层查询与任务能力；专业审批、评估计算和存量系统业务不伪装成已完成。
5. 服务端“办事服务”采用已有系统接入设计。未确认真实地址前，显示接入说明，不编造审批进度或外部链接。
6. 原 oneMap 的完整后台、应用中心与智能中心保留入口，承接本轮没有重做的深层业务。新版浏览器本地流程与原后端数据尚未自动同步。

## 3. 视觉与布局规范

### 3.1 业务端

色彩：主色深松绿 `#174D3E`；文字深灰绿 `#23382F`；纸白 `#FFFFFF`；背景浅灰绿 `#F5F7F4`；分隔线 `#DFE6E0`；面积与耕地专题采用土黄、生态红线采用低饱和红、矿业权采用灰蓝。颜色表达图层含义，不以整页彩色卡片分组。

字体：界面使用系统中文无衬线字体；地图主题标题少量使用宋体；数值使用等宽或表格数字。正文 12—13px，辅助信息 10—11px；页面标题 20—29px。移动端以抽屉承载操作，地图可通过关闭面板恢复。

桌面结构：72px 主导航、54px 区域与搜索栏、约 267px 左目录、可变宽地图、按需出现的 308px 右属性面板、248px 底部属性表。默认右侧面板收起，将主体空间留给地图。950px 以下导航换行；680px 以下目录改为抽屉，详情改为浮层。

### 3.2 公众门户

以实际自然风光构成首屏。短标题“山河有脉，一图相连”配合一个清晰的地图入口。后续依次展开自然专题、数据工具能力、办事入口、指南下载。参考 Apple 官网的主视觉、短文案、主次入口和留白节奏，不复制其品牌标识、产品图片或业务文案。风景照片复用原 oneMap 已登记来源的 Wikimedia Commons 素材，保留摄影者及许可链接。

## 4. 原型交互设计

可视化文档入口为 `requirements.html`。它提供可点击的布局分区说明、各页面状态、主流程和实际可操作原型链接。以下线框与交互规则共同构成需求，不以功能名代替交互设计。

### P01 常驻地图工作台

```text
┌品牌────────一张图│资源│工具│场景│工作台│运营────公众门户┐
├目录开关──行政区选择──搜索地名/图层/对象────────书签──需求文档┤
│ 图层目录              │ 地图主题                    区域概览 │
│ 搜索图层              │                                      │
│ 全部图层 / 已加载     │          常 驻 地 图          工具栏 │
│ ▾ 耕地保护            │                                      │
│ ☑ 永久基本农田        │    点 / 线 / 面 / 行政区       ┌─────┤
│ □ 耕地质量监测        │                                │属性 │
│ ▾ 生态保护            │                                │业务 │
│ ☑ 生态保护红线        │ 图例                           │操作 │
│ □ 自然保护地          │ 自然地理 / 简洁底图             └─────┤
│                      ├对象编号│名称│图层│地区│面积│状态│定位┤
└──────────────────────┴坐标──数据性质说明──────────属性表开关┘
```

|触发|界面响应|状态保持与异常|
|---|---|---|
|选择盟市，或点击行政区轮廓|地图缩放到对应边界；业务对象按区域筛选|行政区下拉框同步；无对象显示明确空结果|
|勾选/取消图层|叠加/隐藏真实示例几何，图例和可见对象数同步|不重置中心与缩放，不把点转换成面|
|切换“已加载”|只显示已加载目录及透明度滑杆|透明度调节只改变样式|
|点击图形对象|高亮并打开属性面板|展示原始几何类型、登记面积、来源及业务属性|
|打开属性表|底部显示当前结果，可分页|每页 20 条；点击名称查看属性；定位按钮联动地图|
|输入关键词并搜索|检索编号、名称、图层、地区；自动叠加命中的图层|空关键词恢复可见对象；无结果保留当前地图供调整|
|切换简洁底图|关闭 DEM，保留行政区和业务对象|图层选择、中心与缩放保持|
|清除绘制与选中|移除测量、临时导入、选择高亮和结果|保留业务目录叠加状态|

### P02 资源预览与申请

```text
资源目录列表 → 点击资源 → 右侧元数据 → 预览并查看属性
                                   └→ 申请示例数据
申请弹窗：资源名称 / 用途 / 行政区范围 / 使用期限
        → 待审核 → 演示管理员查看详情 → 通过 / 退回
        → 通过且未过期 → 下载所选行政区示例 GeoJSON
```

资源元数据包括名称、空间范围、对象数量、几何类型、来源、坐标处理、使用范围与更新方式。目录支持关键词与主题/地区/部门视图；由于原始数据缺少统一部门目录，部门视图明确标注归属待接入，不虚构单位统计。

申请用途至少 4 个字；使用期限为 7/30/90 天。提交后生成申请编号、时间、用途和范围快照。待审核时允许撤回；退回必须有意见；通过后从审核时刻计算到期时间。下载检查本地流程状态及到期时间，并按申请行政区过滤完整图层对象。申请记录跨刷新保留，但只属于同一浏览器的演示状态。

### P03 空间工具箱

```text
工具目录 → 参数面板 → 地图操作 → 范围/结果叠加 → 底部对象列表
```

|工具|输入控件|执行与结果|异常规则|
|---|---|---|---|
|多边形查询|地图顶点、完成、撤销一点、取消|对当前区域内已显示图层执行几何相交；点在范围内、线/面相交均返回|至少 3 点；自相交拒绝；过小范围提示重绘|
|框选查询|地图两个对角点|生成矩形范围并查询|面积过小不执行|
|周边分析|地图选点/当前对象中心、0.1—300km 距离|生成球面缓冲近似多边形，输出相交对象|非数值和越界参数拒绝；中心不是法定地块边界|
|距离量算|至少 2 个路径点|累加球面大圆距离，输出公里|未达到最小点数不结束|
|面积量算|至少 3 个顶点|闭合范围，输出球面近似公顷|自相交、退化图形拒绝|
|坐标转换|经度 -180—180，纬度 -85—85|输出 Web Mercator X/Y（米），地图定位|非有限值或越界输入拒绝；不冒称高精度坐标转换|
|卷帘对照|0—100% 滑杆|左侧底图，右侧专题图层|不是多期影像对比，不生成变化结论|
|本地 GeoJSON 导入|文件选择|预览点线面与 Multi 类型，缩放到范围|最大 5MB、1,000 对象；校验坐标范围与基本结构；仅浏览器读取|

绘图期间通过明显提示条说明下一步；Esc 退出绘制。移动端绘图时收起属性面板，完成后恢复。切换工具会取消未完成的绘制，避免多种鼠标操作同时生效。

### P04 五大业务场景

|场景|默认图层|本轮可操作主线|需继续深化的专业流程|
|---|---|---|---|
|自然资源大管家|土地利用、林地、草原、湿地|选区域→查看对象→查询范围→登记核查任务|指标模型、资产核算、变化追溯、正式资源家底统计|
|国土空间规划|土地利用、建设用地、生态红线|确定范围→叠加管控→查看属性→登记核查意见|规划优化调整、详细规划管控、整治项目业务闭环|
|耕地保护与国土绿化|永久基本农田、质量监测、生态红线|定位耕地→叠加管控→记录线索→核查任务|补充耕地、质量提升评估、矛盾图斑专业分析|
|要素保障|建设用地、基本农田、生态红线、地灾|绘制项目范围→空间查询→汇总对象→协同核查|联动审批、用地供应、真实选址合规规则与跨部门办件|
|矿业权多级一体化审批|采矿权、探矿权、矿山修复|检索矿权→看许可属性→核对关联位置→审查任务|登记许可、有偿处置、电子证照、税务交换、正式多级审批|

场景切换调整默认图层和办理路径，使用同一地图引擎。当前区域继续保留。用户可保存当前图层组合为视图书签。每个场景的操作面板显示对应功能清单编号及本轮边界。

### P05 全局智能助手（浮层，无独立模块页）

```text
任意业务模块 ── 右下角「智能助手」/ Alt+A（Mac 为 ⌥A）── 浮层对话
原有左目录和业务面板保持                    │ 当前区域、图层、选中对象、绘制范围
地图 / 属性表 ← 查询与分析结果              │ 问题 → 执行动作 → 结果说明
申请 / 核查表单 ← 用户确认后提交            └ 收起后继续当前业务
公众门户/需求页 ── 常驻助手 ── 服务引导 / 携带问题进入地图
```

助手为全局工具，不在顶部模块导航占用单独页面。浮层叠在右侧业务面板上，关闭后恢复原面板，切换模块不会清空本轮会话。收起时保留未提交输入；新会话只清空问答上下文，不清空已完成的地图分析结果。旧 `#ai` 链接兼容为“地图页唤起助手”。

|输入/触发|系统交互|结果与限制|
|---|---|---|
|查询呼和浩特市的永久基本农田|识别图层与区域，补充图层，过滤属性表并定位|原有图层保留；支持年份、状态、登记面积及单位条件|
|只看审批中 / 按盟市统计|沿用上轮查询对象继续筛选或统计|说明结果范围；不把统计文字当作新的数据源|
|叠加生态保护红线 / 隐藏生态保护红线|控制地图实际图层和图例|保持当前视图位置|
|分析当前范围|调用当前已绘制多边形的真实相交查询|无多边形时打开范围工具并提示绘制|
|分析选中对象周边10公里|读取当前选中对象中心，生成缓冲区并查询|距离 0.1—300 km；未选对象时提示先选择|
|开始测量面积 / 开始测量距离|唤起量算工具，进入地图选点|助手暂时收起让出绘图区域，完成后可再次唤起|
|创建核查任务|打开预填当前对象、图层、区域与范围的任务表单|由用户填写说明并保存，不自动办结|
|申请当前图层|资源中心使用当前资源；其他模块优先使用选中对象图层|由用户确认用途、区域与期限后提交|
|打开耕地保护场景|切换业务场景与专题图层，更新助手上下文|本轮对话保持，隐藏图层中的选中对象清除|

对违法、合规、新增、趋势等需要业务口径或多期证据的问题，明确提示数据不足，不输出判断。结果来自本地示例对象，不接入大语言模型。真实 NL2SQL、知识引用、多智能体编排属于后续服务接入。公众门户与需求页的浮层提供简要使用引导，空间查询通过携带问题进入同一地图工作台执行。原有完整业务模块也保留这一快速入口；其后台状态尚未与新版地图共享，转入时只传递问题。

### P06 任务工作台

```text
地图对象 / 场景 → 创建核查任务 → 待核查 → 领取 → 核查中 → 填写结果 → 已办结
                         └ 保存对象 ID、区域、图层、中心位置、缩放及绘制范围
```

创建表单包含任务名称、责任单位、核查说明。任务列表显示状态和责任单位；查看详情恢复原地图上下文。领取和办结均写入带时间的记录；办结要求至少 4 个字的处理意见。流程为本地演示核查，不改变原业务审批状态。重新进入页面可查看历史状态。

### P07 数据归集与发布原型

```text
新建登记 → 待质检 → 执行基础校验 ┬ 未通过 → 修改源数据后重新校验
                              └ 通过 → 待编目 → 名称/主题 → 待发布 → 本地发布登记
```

归集对象为现有示例图层；记录登记名、图层、数源单位与时间。基础质检实际检查名称、坐标范围、线最少点数和面环闭合。编目阶段维护中文资源名和主题分类。发布阶段仅完成本地登记，不生成 WMS/WMTS/WFS 服务，不显示虚构服务地址。任务详情的地图始终显示关联图层，便于定位。

现有 oneMap 归集、字段映射、质检整改、标准和配置等完整模块继续保留。原生产式后端流程与新原型不应混为一套共享状态。后续集成时以服务端资源 ID 和状态机替换本地存储。

### P08 公众门户

首屏自然风光与地图入口；五专题标签切换图片、标题、介绍和对应场景；数据与工具入口直达地图工作空间；四个办事入口显示接入方式和关联场景；资讯区提供真实存在的本轮指南、功能说明和文档下载。未编造政策法规标题、发布时间或行政审批办理承诺。

## 5. 全局状态与数据规则

|状态|保存周期|规则|
|---|---|---|
|行政区、图层、透明度、查询结果|当前页面|模块间尽量保留地图上下文；切场景应用默认图层；查询结果说明筛选条件|
|选中对象|当前页面|高亮与属性对应；清除时移除高亮；保持原几何与原登记面积|
|资源申请、核查任务、书签、归集登记、日志|浏览器本地存储|刷新恢复；不代表服务端安全授权；不跨设备同步|
|助手上下文|当前页面/会话|新会话清空；不称为长期用户画像|
|导入 GeoJSON|当前页面内存|不上传、不自动入库；清除或刷新后消失|
|审批与下载期限|本地演示逻辑|到期禁止示例申请下载；完整生产权限必须落在服务端|

源数据包括 28 个图层、1,176 个对象，其中 1,018 个原业务示例、158 个乡镇示例点；附带 12 个盟市和 103 个旗县参考边界。沿用 oneMap 已转换的运行坐标，不进行第二次重复偏移。DEM 来源为原 demo 缓存，范围记录于原 build.log：97°—126.1°E、37°—53.5°N；显示前按纬度重采样到墨卡托行序。所有几何量算与登记属性分开显示。

## 7. 接口与落地设计

新版保留清晰的地图视图状态、对象 ID、图层 ID、任务和申请数据结构。接入原后端时优先改造资源适配层，不重写地图布局。建议映射关系：图层目录→原资源与集成接口；查询→权限过滤后的空间服务；申请审核→原申请与授权模块；任务→原流程与消息总线；归集→原运营中心；助手→原地图查询计划及受约束执行接口。前端 localStorage 仅用于当前 demo，不作为正式数据源。

生产接口需返回可见范围、字段权限、几何类型、坐标参考、版本、来源与服务状态；所有下载、查询与记录恢复均在服务端重新校验权限。正式地图接入前核验数据坐标系及转换精度，不将天地图或任一底图品牌直接等同于某个偏移坐标系。

## 8. 验收与演示脚本

1. **地图资源发现**：全区视图→选呼和浩特→勾选耕地/生态图层→开属性表→点击对象→定位。区域与表格结果一致，图层切换不重置视图。
2. **空间查询**：工具中心→框选或多边形→完成→查看相交对象→导出本页。空范围提示、取消绘制、自相交处理均有效。
3. **资源使用**：资源详情→填写申请→工作台查看待审核→切管理员→通过→下载。退回理由与到期规则另作测试。
4. **业务任务**：选对象→建立任务→工作台打开→恢复地图→领取→填写意见办结。刷新后能恢复记录。
5. **数据运营**：新建登记→实际基础质检→编目→本地发布登记。逐阶段按钮与记录同步。
6. **助手协同**：任意模块唤起→读取当前地图上下文→叠加图层/查询/周边分析→任务或申请表单→收起恢复业务面板。验证快捷键、跨模块会话、查询追问及专业结论边界。
7. **公众门户**：五主题切换→相关场景跳转→办事接入说明→文档下载。
8. **兼容性**：桌面与手机宽度检查；本地依赖离线加载；浏览器日志无本应用错误；原路径仍可到达原业务模块。

具体已执行结果见《验收记录.md》，不把计划中的验收脚本写作已通过。

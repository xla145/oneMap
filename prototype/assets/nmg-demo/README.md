# 内蒙古一张图 demo 提取包

来源：`bak/内蒙古一张图demo`。原始文件保留不变。

- `index.html`：原版完整独立地图页面，可双击打开；在线底图仍需网络。
- `data/nmg_*.js`：从原目录逐文件复制，保留原始字段和坐标。
- `data/nmg_*.json`：上述数据的纯 JSON 版本，便于复用。
- `data/runtime.json`：新版 OpenLayers 工作台使用的运行数据，几何近似转换到经纬度；原始数据未修改。
- `nmg_terrain_admin.png`：原本地地形行政区底图。
- 四份 `*.geojson`：自治区、盟市、旗县和行政中心原始数据。
- `manifest.json`：来源、数量、文件大小和 SHA-256 校验信息。

源业务数据共28个图层定义、1018个业务要素；乡镇点位独立存储，共158个。适配器把乡镇补入原本只有目录定义的乡镇图层，新版运行地图共1176个对象，不改变原1018个业务要素。另含103个旗县边界、12项五年指标、区域统计、专题POI以及4个模块40项业务功能定义。

新版实际显示及查询点、线、面原始几何；保留业务登记面积，绝不把点状业务对象伪造成地块多边形。时序指标与其他汇总统计的口径分别保留，所有内容均为参考demo素材。

重新提取：在仓库根目录运行 `node prototype/extract-nmg-demo.mjs`，再运行 `python3 prototype/prepare-nmg-runtime.py`。

在线入口：`http://127.0.0.1:5190/assets/nmg-demo/index.html`。

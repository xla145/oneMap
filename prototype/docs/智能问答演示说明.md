# 门户智能问答演示

入口：办事服务 → 常用办事 / 数据对比，或智能助手新对话欢迎页。点击问题自动选择对应助手并开启新会话，避免沿用其他示例的区域和时间。

常用问题包括用地审批进度、数据申请材料、不动产登记查询和耕地占补平衡。办事回答引用当前已发布的门户指南，政策问题走知识助手。

## 对比样本

使用已有已发布资源 `r2 / demo_cropland`，无需覆盖已有数据库。所有数据为虚构样本。

| 年份 | 地区 | 耕地面积（公顷） | 保护目标（公顷） |
| --- | --- | ---: | ---: |
| 2025 | 呼和浩特市 | 350 | 420 |
| 2026 | 呼和浩特市 | 400 | 420 |
| 2025 | 包头市 | 250 | 300 |
| 2026 | 包头市 | 280 | 300 |

预设问题及默认样本结果：

- 2026 年两市面积对比：400 与 280 公顷，包头市较呼和浩特市少 120 公顷。
- 呼和浩特市两年变化：350 → 400 公顷，增加 50 公顷，增长 14.29%。
- 呼和浩特市面积与目标：400 / 420，差额 -20 公顷，达成比例 95.24%。
- 两市达标指数：95.24% / 93.33%，相差 1.91 个百分点。

结果实时读取已发布指标 `i_area / i_target / i_rate`，显示明细、单位、版本、来源与口径。编辑或下架指标、资源后，结果随之变化；保留现有智能体范围和区域授权校验。缺失年份或无权限不生成部分对比，基期为零不计算增长率。采用规则识别，不接入外部大模型。

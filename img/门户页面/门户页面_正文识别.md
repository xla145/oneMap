# 5.4.1.2. 统一门户（服务端）

> 来源：IMG_8420.HEIC、IMG_8421.HEIC、IMG_8422.HEIC（原文第 197—199 页）。本文识别整理“统一门户（服务端）”章节，保留原文编号并合并跨页段落，不包含图片中相邻章节内容。原文导航中的“壮美内蒙古”与章节标题“大美内蒙古”表述不同，此处按原文保留。

自治区自然资源“一张图”（服务端）是自治区自然资源部门对外的统一服务窗口，依托政务云互联网区，面向社会公众、企事业单位、科研院所，提供权威的自然资源数据共享、工具共享、便捷的办事服务、丰富的资讯下载、直观的空间查询，同时突出内蒙古生态屏障、能源基地、草原文化等特色，打造“看得见、用得上、有特色”的自然资源公共服务平台。

## 5.4.1.2.1. 门户首页

门户首页是服务端的总入口，集信息汇聚、服务导航、资源展示于一体。顶部设置导航栏（首页、数据服务、能力服务、办事服务、资讯下载、壮美内蒙古），中部提供核心快捷入口（地图浏览、数据申请、常用工具、办事服务），并展示政策法规滚动通知、热门数据推荐。用户可通过全局搜索框快速检索数据、工具或资讯。

## 5.4.1.2.2. 数据服务

数据服务模块是权威自然资源数据的“超市”，按自治区实际需求主题分类展示数据目录，支持关键词检索与筛选。每个数据详情页展示元数据（来源、更新日期、空间范围、使用限制），提供地图在线预览功能。用户可在线填写用途和期限发起数据申请，管理员后台审核通过后自动开放下载或 API 授权。同时推荐热门数据，并提供标准 OGC 地图服务及 REST API 接口，供开发者调用。

## 5.4.1.2.3. 能力服务

能力服务模块集成常用的空间分析与合规性审查工具，降低用户技术门槛。主要包括缓冲区分析、面积量算、坐标转换、叠加分析等基础工具，以及项目选址、合规性审查等高级工具。用户上传地块坐标或规划数据，系统自动分析是否符合生态红线、永久基本农田等管控要求。工具市场展示国家级和自治区级共享模型，支持在线体验，满足企业、科研机构及开发者的多样化分析需求。

## 5.4.1.2.4. 办事服务

办事服务模块整合自然资源领域面向公众和企业的线上服务入口，实现“一窗办事”。提供不动产登记信息查询（权属、面积、抵押状态）、用地审批进度实时跟踪（输入项目编号）、矿业权基本信息与有效期查询。同时发布国土空间规划草案、成果及修改方案的公示，接受公众意见反馈。集成基准地价查询、办事指南（含材料清单、办理流程、咨询电话），大幅提升政务服务便捷度和透明度，助力优化营商环境。

## 5.4.1.2.5. 资讯下载中心

资讯下载中心汇集政策法规、行业动态、技术标准浏览及下载能力。政策法规栏目分类发布国家与自治区自然资源法律、规章、规范性文件；行业动态及时更新工作新闻、通知公告。技术标准提供数据规范、技术规程等文档下载。用户可免费下载使用，实现政策信息与业务工具有效供给，支撑日常工作与学习研究。

## 5.4.1.2.6. 大美内蒙古

大美内蒙古是“一张图”互联网版的特色展示窗口，旨在通过地图、影像、图表、文字等多种形式，集中展现内蒙古独特的自然地理风貌、国土空间规划格局、能源资源禀赋、社会公共服务以及生态安全屏障建设成效。模块以“生态优先、绿色发展”为主线，将专业地理信息与公众认知相融合，打造兼具科普性、可读性和互动性的线上空间，让公众直观感受内蒙古的壮美风光与高质量发展成就，增强生态保护意识和国土空间治理认同感。

## 5.4.1.2.7. 后台管理

后台管理系统为平台稳定运行提供管理支撑。数据管理模块支持数据服务的发布、下架、更新，元数据编辑及用户申请审核；工具管理模块负责工具的注册、上下架与调用统计；用户管理模块实现用户注册审核、角色权限分配及访问分析；内容管理模块用于资讯、政策、下载资源的发布维护；日志审计模块记录操作日志、访问日志及 API 调用日志，便于安全溯源。

# 统一门户（服务端）功能清单

> 来源：《一张图可研附表2.1.pdf》PDF 第 21—24 页，其中门户内容对应印刷页码 563—567。提取原表第 2 项“统一门户（服务端）”，共 7 个模块、48 项功能。保留功能编号、名称与说明，合并跨页内容，并依据页面图像修正文字层识别错误；不收录原表的测算数值列及相邻章节。

## 2.1 门户首页

| 编号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 2.1.1 | 门户基础框架开发 | 设计并开发门户整体布局，包括头部导航区、中部内容区、底部功能区，实现响应式页面框架。 |
| 2.1.2 | 全局搜索功能 | 支持对数据、工具、资讯等内容的关键词检索，提供热门搜索词推荐。 |
| 2.1.3 | 核心快捷入口 | 设置地图浏览、数据申请、常用工具、办事服务等图标按钮，一键跳转对应模块。 |
| 2.1.4 | 动态信息展示 | 在首页展示政策法规滚动通知、行业动态、热门数据推荐等动态信息。 |
| 2.1.5 | 个人中心 | 实现用户注册、登录、信息维护、申请记录查询、消息通知、收藏夹等功能。 |
| 2.1.6 | 角色化视图 | 根据登录身份（普通用户、企业用户、管理员）展示不同的首页内容和操作权限。 |

## 2.2 数据服务

| 编号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 2.2.1 | 服务目录管理 | 支持按主题分类展示数据列表，提供多维度筛选和关键词检索。 |
| 2.2.2 | 元数据展示 | 每个数据详情页展示来源、更新日期、空间范围、使用限制、格式等完整元数据信息。 |
| 2.2.3 | 地图在线预览 | 集成地图引擎，支持对数据图层进行在线浏览、缩放、平移、叠加显示。 |
| 2.2.4 | 数据申请流程 | 用户在线填写申请用途、使用期限、数据范围等，提交后进入审核流程。 |
| 2.2.5 | 申请审核管理 | 管理员对数据申请进行审批，通过后自动开通下载权限或生成 API 调用凭证。 |
| 2.2.6 | 数据下载 | 审核通过后提供数据包下载链接（支持按行政区划或空间范围裁剪）。 |
| 2.2.7 | 数据服务 API 发布 | 将可共享的图层发布为 OGC 标准服务（WMS/WMTS/WFS）或 REST API，供开发者调用。 |
| 2.2.8 | API 密钥管理 | 用户申请 API 密钥，管理员审核，支持密钥启用、停用、调用量统计。 |
| 2.2.9 | 热门数据推荐 | 基于下载量、访问频次自动统计并推荐热点数据，提升数据发现效率。 |
| 2.2.10 | 数据统计看板 | 后台展示数据总数、服务调用量、申请次数、下载量等统计图表。 |

## 2.3 能力服务

| 编号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 2.3.1 | 基础空间分析工具 | 提供缓冲区分析、面积量算、坐标转换、叠加分析等在线工具，用户输入参数即可运行。 |
| 2.3.2 | 项目选址及合规性审查工具 | 用户上传地块坐标或范围，自动分析是否符合规划、生态红线、基本农田等管控要求，生成审查报告。 |
| 2.3.3 | 能力共享市场 | 分类展示国家级和自治区级共享的分析模型及工具，支持在线体验和参数配置。 |
| 2.3.4 | 工具调用 API | 将常用工具封装为 API 服务，供外部系统集成调用，需申请密钥。 |
| 2.3.5 | 能力服务申请与管理 | 管理员对工具服务进行注册、上下架、版本管理、调用统计和权限分配。 |
| 2.3.6 | 使用教程 | 每个能力服务提供详细说明文档、参数示例和操作视频，降低用户学习成本。 |

## 2.4 办事服务

| 编号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 2.4.1 | 不动产查询入口 | 对接自治区不动产登记平台，提供跳转链接或集成查询界面，支持房屋权属、面积、抵押信息查询。 |
| 2.4.2 | 用地审批进度查询 | 输入项目编号或报件号，实时返回审批阶段（初审、会审、办结）及预计办结时间。 |
| 2.4.3 | 矿业权信息查询 | 提供探矿权、采矿权基本信息（许可证号、矿种、面积、有效期）的在线检索。 |
| 2.4.4 | 规划公示 | 发布国土空间规划草案、成果、修改方案等，支持公众查看和意见反馈。 |
| 2.4.5 | 地价查询 | 展示基准地价、监测地价信息，可按行政区、土地级别、用途分类检索。 |
| 2.4.6 | 办事指南 | 集成自然资源行政审批事项的流程、材料清单、办理时限、咨询电话等信息。 |
| 2.4.7 | 在线咨询与留言 | 提供简单的咨询留言功能，用户提交问题后管理员后台回复，支持公开问答展示。 |

## 2.5 资讯下载中心

| 编号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 2.5.1 | 政策法规管理 | 按分类（法律法规、部门规章、规范性文件）发布和管理政策内容，支持附件上传。 |
| 2.5.2 | 行业动态管理 | 发布自然资源工作新闻、通知公告、会议信息，支持图文混排和附件下载。 |
| 2.5.3 | 技术标准文档库 | 提供各类技术规程、数据标准、操作规范等 PDF 文件的上传下载及分类检索。 |
| 2.5.4 | 培训资源管理 | 上传操作手册、视频教程、演示 PPT 等，支持在线观看或下载。 |
| 2.5.5 | 内容检索与推荐 | 支持全文检索，根据用户浏览记录推荐相关内容。 |

## 2.6 大美内蒙古

| 编号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 2.6.1 | 自然地理风光专题 | 以地图形式展示内蒙古草原、森林、沙漠、河流、湖泊等典型自然景观的空间分布，并配风光图片、短视频和生态介绍。 |
| 2.6.2 | 国土空间规划专题 | 面向公众提供规划成果摘要、规划图集在线阅读，支持查询所在地的规划管控要求，提升规划透明度和公众参与度。 |
| 2.6.3 | 重要能源保障基地专题 | 专题展示煤炭、稀土、风能、太阳能等资源分布图，附带开发规划介绍。 |
| 2.6.4 | 社会公众服务专题 | 集成各类公共服务站点、地灾避险场所等便民信息，提供位置查询，提升自然资源公共服务可及性。 |
| 2.6.5 | 北疆安全生态屏障专题 | 系统展示“三北”防护林、退牧还草、京津风沙源治理、湿地保护恢复等重大生态工程实施范围与成效。 |
| 2.6.6 | 专题内容管理（后台） | 为管理员提供可视化的专题内容后台管理功能，支持对上述五个专题的展示内容进行灵活配置与更新。 |

## 2.7 后台管理系统

| 编号 | 功能名称 | 功能说明 |
| --- | --- | --- |
| 2.7.1 | 数据管理 | 数据的发布、下架、更新，元数据编辑，数据申请审核，数据服务配置。 |
| 2.7.2 | 工具管理 | 工具的注册、上下架、版本管理、调用统计、API 密钥审核。 |
| 2.7.3 | 用户管理 | 用户注册审核、角色分配（普通用户/企业/管理员）、访问日志统计。 |
| 2.7.4 | 内容管理 | 资讯、政策、技术标准、软件工具等内容的发布、分类、编辑、删除。 |
| 2.7.5 | 日志审计 | 记录用户操作日志、访问日志、API 调用日志，支持检索、导出和审计。 |
| 2.7.6 | 安全配置 | SSL 证书配置、IP 白名单、防爬虫策略、数据库备份还原设置。 |
| 2.7.7 | 系统监控 | 监控系统 CPU、内存、磁盘使用率，服务响应时间，异常告警通知。 |
| 2.7.8 | 统计分析 | 统计用户活跃度、数据/工具调用量、热门资源排行、申请审批通过率等。 |

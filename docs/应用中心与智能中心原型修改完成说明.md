## 推荐演示顺序

1. 门户进入耕地保护专题，点击图斑，向助手提问“查询耕地保有量指标”，查看业务上下文与返回入口。
2. 工作台发起项目辅助审查，提交材料，切换办理身份处理节点，再查看办理历史。
3. 后台配置地图场景，编辑应用并提交审核，核对审核前后前台版本。
4. 修改并发布流程和表单，比较新旧办件的配置快照。
5. 试调用网关，查看事件投递、失败渠道和重试记录。

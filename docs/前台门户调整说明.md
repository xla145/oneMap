# 前台门户调整说明

日期：2026-09-15

## 调整目标

将前台从内部工作台布局调整为自然资源智能服务门户。首页负责展示、发现和引导；用户选择资源或智能能力后进入具体使用页面。后台继续承载资产维护、发布、审批与运行管理。

## 页面与入口

| 区域 | 调整结果 |
| --- | --- |
| 全站导航 | 移除前台管理侧栏，使用顶部品牌、横向主导航、智能助手入口和右上角个人服务。 |
| 首页 | 大搜索框、热门探索、四类资源入口、推荐智能体、推荐资源、五类服务、业务知识与使用指引。 |
| 资源中心 | 复用资源筛选、详情、申请清单；首页资源分类可直接带类型进入。 |
| 智能体广场 | 展示已发布智能体及适用场景，选择后进入独立会话页。 |
| 工具与服务 | 面向业务用户提供资源语义解读、指标分析、知识问答、场景提问、个性化服务；不在门户暴露资产编辑表单。 |
| 知识中心 | 新增知识列表、搜索分类、正文阅读、来源和版本展示，以及知识问答入口。 |
| 助手会话 | 保留多轮对话、引用、指标、申请与任务接续；有明确的“返回门户”入口。 |
| 个人服务 | 右上角进入我的申请、个人中心与历史会话，支持切换演示身份。 |
| 页脚 | 资源中心、知识中心、使用指南与后台入口，说明原型内容边界。 |
| 移动端 | 顶部折叠菜单、单列内容和卡片；导航跳转后自动收起。 |

## 实现与数据

本轮修改 `prototype/app.js`、`prototype/style.css` 和 `prototype/index.html`，复用现有后端接口。门户样式限定在前台，后台继续使用独立管理布局。

首页推荐内容来自当前用户可见的已发布资源、知识与智能体。首页不显示个人申请量、个人对话量等工作台统计；这些记录保留在个人服务中。未新增虚构的通知公告或政策发布内容。

首页搜索和场景入口会开启相应智能体的新会话；已有会话可以在个人中心或助手历史列表中继续。现有申请、授权、反馈与配置数据保持原状。

## 验证方式

`prototype/check_portal_browser.py` 使用 agent-browser 验证门户导航和业务跳转，并在 1440、1024、390 像素宽度检查页面。涉及提问的交互在独立测试数据库进行，不写入当前演示数据。

```sh
python3 prototype/server.py --port 5194 --db /tmp/onemap-portal-test.sqlite3
DEMO_QA_URL=http://127.0.0.1:5194 python3 prototype/check_portal_browser.py
```

浏览器截图位于 `prototype/screenshots/portal-*.png`，结果位于 `prototype/portal-browser-checks.json`。

## 本轮验证结果

36 项门户浏览器检查全部通过，JavaScript 语法检查通过。已检查首页、工具服务及助手截图，桌面/平板/手机页面未发现整体横向溢出，浏览器未报告脚本错误。

# 对外门户优化实施说明

日期：2026-09-15。

本轮依据[对外门户现状评估与优化方案](对外门户现状评估与优化方案.md)实施，完成公共门户入口重组，并增加可运行的数据获取、基础空间工具、公众反馈及专题运营流程。代码位于 `prototype/`，继续使用现有 Python、SQLite、原生 JavaScript 和 OpenLayers。

## 3. 已验证的业务流程

### 数据申请到下载

1. 业务用户进入资源详情，将未授权资源加入清单。
2. 点击“填写并提交申请”，填写用途与有效期。
3. 切换审批人员，在资源申请对接中审核通过。
4. 切回申请人，资源显示“已授权”，可下载已有示例数据。
5. “我的咨询与意见”页面下方保留个人下载记录。

浏览器实测使用独立测试数据库中的 `r1`，验证提交、审批、授权状态和 CSV 下载记录。单元测试另覆盖未授权、过期、已停用和不可见资源的拒绝逻辑。

### 公众意见到回复

1. 在规划公示或服务说明页提交意见/咨询。
2. 前台进入“我的咨询与意见”，显示待受理记录。
3. 管理员进入“公共门户运营 → 公众反馈”，受理或填写回复。
4. 提交者可查看处理状态和回复历史。

重复提交使用幂等标识避免新增重复记录；其他普通用户无法读取该提交者的记录，普通用户不能调用后台回复操作。

### 专题维护到前台展示

1. 管理员编辑专题介绍、正文或关联资源，保存草稿。
2. 发布前，对外继续展示旧的已发布版本。
3. 发布后，前台详情与关联资源同步新内容，地图仅加载符合访问权限的已绑定图层。
4. 下架后，列表不再展示，直接访问详情也提示不可用。

浏览器实测修改专题简介、关联示例图层、保存并发布，确认前台新文案和关联数据生效。单元测试覆盖旧修订号冲突。

## 4. 数据与实现边界

- 现有演示身份机制保持不变，未新增正式游客权限模型、个人/企业注册认证或国家统一身份接入。当前页面展示为演示身份登录后的原型体验。
- 正式不动产、用地审批、矿业权、地价查询接口仍需对接；当前进度查询来自本地授权办件，公示内容为示例。
- 坐标转换仅支持 WGS84 经纬度与 Web Mercator 数值转换；量算和点缓冲为球面近似。暂不支持跨日期变更线、多孔洞或自相交多边形，不做测绘基准转换。
- 缓冲区为点缓冲，距离支持大于 0 至 100000 米。复杂图层缓冲、叠加及自动合规审查仍需后续计算服务和正式规则。
- 下载内容是已有授权示例数据；没有绑定几何的图层不会伪造可下载数据包。正式 OGC 发布、REST 数据服务、API 密钥、区域裁剪和批量下载任务仍需后续接入。
- 本轮未新增 PDF/视频原始附件上传播放、全套专题媒体、真实统计图表和访问热度统计；资讯保留 TXT 正文下载，专题采用已有示意封面和可维护正文。
- 当前资源、知识和身份继续沿用原型的权限模型。正式互联网发布需要进一步区分内部发布与公众公开范围；本轮没有把演示环境视为生产公共服务。

- Python 单元测试：103 项通过，包含本轮新增 11 项门户测试。

## 菜单切换初始化请求优化

前端初始化数据改为页面内存缓存，按用户和前后台模式区分，有效期 30 秒，同时发生的请求合并。路由切换及窗口聚焦在有效期内复用数据；手动刷新、保存后的刷新保留强制请求。业务操作使缓存失效，地图读取和浏览埋点不使缓存失效；身份切换清空缓存。缓存不写入 localStorage/sessionStorage，也不共享到 Nginx。

缓存过期后，在下一次导航或聚焦时获取最新数据；其他用户的修改可能最多延后约 30 秒在这些刷新触发点体现，手动刷新可立即拉取。

验证：4 项 Node 缓存测试通过；公网浏览器连续切换前台栏目及后台菜单均新增 0 次 bootstrap 请求，手动刷新新增 1 次，无脚本错误。更新文件为 app.js、index.html、frontend/bootstrap-cache.js。更新前前端文件备份在 `/opt/onemap/backups/bootstrap-cache/`。

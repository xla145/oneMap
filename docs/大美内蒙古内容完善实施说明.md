更新日期：2026-09-16。

## 本次交付

依据原清单 2.6.1～2.6.6，将五个专题入口完善为带有总览地图、专题导读、资料区和服务入口的公众展示页面。

- 首页：简短引导、主题插画、行政区总览地图、盟市定位和五个专题卡片。
- 封面：增加五种原创 SVG 主题插画，替换原先的系统界面示意图，明确标注“非实景影像”；支持后台配置经授权的 HTTPS 实景封面与来源。
- 自然地理：草原、森林、沙漠、河流与湖泊四组科普导读。
- 国土空间规划：规划层次、图集阅读、所在地查询前提与公示参与，衔接规划公示入口。
- 能源资源：煤炭、稀土、风能和太阳能四类介绍，区分资源、项目、规模与产量等概念。
- 社会公众服务：办事地点核对、不动产和用地服务、地灾避险信息使用说明，关联现有便民服务。
- 生态屏障：“三北”防护林、退牧还草、京津风沙源治理、湿地保护恢复四组导读，明确成效判断需同口径资料。
- 详情：专题导航、左侧地图与右侧章节、发布说明、资料状态、影像资料和相关数据入口。
- 后台：最多六个章节、六项媒体资料；支持图片、视频、图集/文档链接，保留草稿保存、发布、下架和关联资源流程。

首页及详情继续使用实际已发布的专题名称、简介、来源、顺序和关联资源。缺少章节配置时展示本次编写的默认导读；管理员保存章节后使用发布内容，显式保存空章节不会重新补回默认文本。已有自定义正文保留在“查看发布说明”。未修改已有专题数据库内容，不重置已发布记录。

## 使用入口

- 前台：`http://127.0.0.1:5190/#/front/landscape`。
- 后台：`/#/admin/public-portal?tab=topics`，管理员编辑专题。
- 分节内容、媒体和封面保存为草稿后，需要点击“发布”才对公众生效。
- 图片、视频、图集填写业务单位核实的 HTTPS 地址，并填写来源；外部资源须允许实际浏览/播放。

## 当前边界

本次新增的是专题内容与展示能力，不表示正式专题数据已接入：

| 内容 | 当前情况 |
|---|---|
| 典型景观的精确位置、实景图片与视频 | 待核实资料；现有封面为原创插画 |
| 所在地规划管控查询、正式规划图集 | 尚未接入；提供阅读指引和规划公示入口 |
| 矿产、能源基地正式分布和统计图表 | 待发布，不虚构资源储量或产能 |
| 公共服务站点和避险场所实际点位 | 待核实，不提供虚构路线或实时避险导航 |
| 生态工程实施范围、分年度成效、前后影像 | 待正式资料，不编造图斑、成效指标 |
| 媒体上传与托管 | 当前配置外部 HTTPS 地址，未新增文件上传/转码服务 |

专题地图只加载后台关联且当前用户具备访问权限的图层。没有关联专题数据时显示行政区底图并明确提示；盟市定位属于地区认知，不代表景观或工程边界。导读为公众科普说明，不替代批准成果、统计公报或紧急指引。

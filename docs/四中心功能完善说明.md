# 四中心功能完善说明

更新日期：2026-09-16。实现位置：`prototype/`，数据保存于本地 SQLite。本次在现有后台上补充可操作页面和业务流程；原始可研中的外部系统联调、正式数据平台部署仍需后续实施。

## 1. 入口与职责

| 中心 | 本机入口 | 管理职责 |
| --- | --- | --- |
| 综合集成 | http://127.0.0.1:5190/#/admin/center-integration | 系统接入、资源汇聚、待办集成、纵向节点、同步记录 |
| 资源中心 | http://127.0.0.1:5190/#/admin/center-resources | 共享目录、资源编目、使用申请、授权交付、订阅 |
| 工具中心 | http://127.0.0.1:5190/#/admin/center-tools | 工具注册、配置审核、发布下架、接口试运行 |
| 运营中心 | http://127.0.0.1:5190/#/admin/center-operations | 数源登记、数据归集、质检整改、标准建库、技术发布、业务巡检 |

使用端新增“综合工作台” `/#/front/integrated-workbench` 和“资源中心” `/#/front/shared-resources`，提供可见资源、本人待办、收藏、交付领取、订阅管理及本人治理工单。

后台沿用现有身份、授权、门户工具和资源主记录。技术发布属于运营中心，共享编目和交付属于资源中心；资源授权仍复用原有申请审批及授权台账。

## 2. 综合集成

- 汇聚数据库表、图层服务、工具服务、知识、智能体、应用场景和门户工具，支持搜索、类型/目录筛选、排序、收藏及原页面直达。
- 按可研预置 9 个系统接入台账，支持入口、认证客户端、关联应用、联系人、适配方式和待办映射配置。
- 系统配置检查明确返回缺失项；前 8 个接入系统检查单点登录客户端，厅门户为入口接入。配置通过后仍标注待联调。
- 国土空间规划、耕地保护系统预置待办集成开关。实际支持 JSON 导入，映射来源标识、标题、处理人、状态、期限和入口；按来源系统和来源标识去重更新，整批验证失败不写入。
- 展示待办、已办、逾期和临期预警；普通用户仅看到本人的外部待办。
- 管理自治区及下级节点、上下级关系和交换方向；校验层级与循环引用，按配置导出目录交换 JSON，保留同步记录。

当前节点用于交换配置，不提供独立租户隔离。配置校验不代表外部网络、单点登录或待办接口已联通；交换清单只生成本地文件。

## 3. 资源中心

- 共享目录支持上下级结构；资源编目可设置目录和标签，支持包含子目录的筛选。
- 申请单支持数据下载、数据订阅、定时推送、数据服务、功能接口、离线获取和数据访问，按资源类型校验兼容方式。
- 审批通过后生成关联申请及授权的交付记录。管理人员可准备交付、查看失败原因并重试。
- 数据交付实际生成 CSV，按接收人的现有授权、行政区和可显示字段过滤；下载时再次校验授权、资源版本和字段范围。
- 服务和功能接口交付校验已绑定地址；领取服务入口时重新校验权限。
- 离线获取支持领取地点、时间、通知及领取确认。
- 订阅支持周期设置、暂停、恢复和手动生成批次；后台定时任务生成本地交付包，授权失效后暂停。
- 平台管理员和资源审批人员可处理交付，普通用户仅查看、领取本人的交付与管理本人订阅。

订阅接收端为本地交付箱，未向外部 HTTP 接口推送。字段筛选作用于本次交付或服务查询，不等同于全平台字段级权限系统。

## 4. 工具中心

- 工具台账补充提供方、接口说明、输入示例、输出说明、访问人群及关联工具资源。
- 新增“提交审核 → 通过/驳回 → 发布”流程。审核绑定当前配置，编辑后原审核失效；历史已发布版本继续可用，后续发布必须审核。
- 上架审核记录保存处理结果和意见，支持下架。
- 后台试运行保存输入、真实输出、异常和耗时；支持坐标转换、面积、缓冲区、叠加、合规性核查及本地空间数据检查/查询/入库/编辑。
- “登记内部组件模板”可补充空间检查、查询、入库、编辑四类草稿，不自动发布；重复登记不会重复创建。
- 空间写操作校验版本，限制为管理员工具，写入独立的本地工作图层。

外部工具通过实际登记入口联调，本地不返回模拟成功。空间编辑不修改生产 GIS，也不会自动改动现有地图发布场景；合规核查仍受现有示例图层和规则覆盖范围约束。

## 5. 运营中心

| 功能 | 已实现行为 |
| --- | --- |
| 运行总览 | 归集、待质检、未办结工单、入库、发布和交付异常统计，流程入口 |
| 数源登记 | CSV、数据库及 GIS 数源元数据登记；外部数源标记待联调 |
| 归集批次 | 在线 CSV 填报或文件读取、数据标准和规则选择、提交及退回 |
| 质检规则与报告 | 必填、唯一、非负数等字段检查，输出行号、字段、问题值及规则依据 |
| 治理工单 | 从报告发起、指派处理人、提交修正数据和处理依据、实际复检、通过办结 |
| 数据标准 | 字段名称、类型、必填约束、发布及版本历史 |
| 建库管理 | 按发布标准创建空表；质检通过后登记资源草稿，记录血缘与标准版本 |
| 技术发布 | 本地数据查询接口发布、试查询和停用；外部协议服务登记 |
| 业务巡检 | 检查失败交付、未解决数据质量问题及技术服务资源依赖异常 |

登记入库前检查数据内容、规则版本、标准版本以及工单状态，避免使用过期报告。已分派工单的处理人可以从综合工作台反馈整改，但不能自行复核办结。

本地查询接口按发布资源版本执行搜索、分页、区域和字段过滤，并检查调用人的资源授权。资源更新后旧服务版本不能继续直接查询，需重新发布。

CSV 当前限制为 UTF-8、最多 200KB、2000 行、100 个唯一英文列名。数据库/GIS 适配器、GDB/MDB、生产级调度 ETL 和外部数仓尚未实现。WMS、WMTS、WFS、MapService 等仅登记外部服务，不由本原型生成 GIS 服务。

## 6. 推荐验收流程

1. 运营中心新增 CSV 归集批次，将某行 `area` 填为负数，提交并执行质检。
2. 在失败报告发起工单；处理人反馈修正后的 CSV，管理员执行复检复核。
3. 返回归集批次登记入库，在技术发布中关联新资源，发布本地数据接口并试查询。
4. 在资源中心为该资源编目；业务用户提交使用申请，审批后准备交付，用户领取数据。
5. 撤销授权，再次下载或查询应被拒绝；订阅在执行时应暂停。
6. 在工具中心修改工具配置、提交审核、审核通过后发布，再执行接口试运行查看实际结果。
7. 在综合集成导入来源系统待办，用对应处理人身份查看；重复导入同一来源标识应更新而非重复生成。

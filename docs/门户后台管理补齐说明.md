## 菜单与前台联动

- 门户相关的数据、工具、用户、内容与统计入口统一归入“门户管理”，内部分类也支持折叠。系统监控、日志审计、安全配置归入独立的“系统管理”。应用中心、智能中心、公共支撑保留为独立折叠组。
- 菜单记住折叠状态；导航到其他分组页面时自动展开该页面所在组，并突出当前子菜单。桌面与移动端均使用同一套分组。
- `/#/front/register`：从个人服务进入账号申请，查看本人审核结果。
- `/#/front/api-keys`：申请工具/数据密钥，审核通过后领取。明文密钥只显示一次，数据库仅保留摘要。
- `/#/front/capabilities`：读取已发布且有权限的工具。下架或权限变化后，新的浏览器调用及 API 调用会被拒绝。
- `/#/front/knowledge`：展示已发布资料附件，关联资讯的附件继承该资讯的可见性，未发布草稿和文件正文不进入初始化接口。
- 注册、工具、资料与密钥记录增量写入 SQLite，不重置现有资源、申请及内容。

## API

- `POST /api/v1/tools/invoke`，请求体示例：`{"toolId":"coordinate","parameters":{"x":111.7,"y":40.8}}`。
- `POST /api/v1/data/query`，请求体示例：`{"resourceId":"r2"}`，返回授权的本地数据包内容。
- 使用 `Authorization: Bearer <密钥>`；服务范围、当前用户状态、授权、有效期和服务发布状态都在调用时检查。响应含请求标识，可关联日志。

## 实现边界

- 仍使用已有演示身份机制；企业用户是门户角色，未接入企业实名认证或生产 SSO。
- 数据源配置提供授权后的外部服务入口；没有凭空生成正式 OGC 服务，也不代理需要提供方凭证的业务 API。正式数据、业务接口、TLS 证书及私钥需要由实际部署提供。
- HTTPS 修改需要重启 Python 服务。IP 白名单保留回环地址用于本机恢复。限流在当前进程生效，反爬为请求频率和 User-Agent 规则，不包含分布式 WAF 或验证码。
- 备份在数据库相邻目录 `<数据库名>-backups/`，包含数据库中的附件与日志；证书文件不包含在备份中。还原会替换当前数据库，页面要求输入备份名称确认。
- 告警通知在本地后台展示，未向短信、邮件或钉钉发送消息。支持 macOS/Linux 指标采样；取不到的指标显示暂无数据，不填造数值。
- 外部工具统计入口打开次数；浏览器工具统计客户端报告的计算结果；异步分析的调用成功表示任务已受理，最终计算结果以任务记录为准。热门资源按详情浏览与数据下载次数汇总；审批通过率按所选期间提交申请中已审核的明细计算。

## 验证

使用独立测试数据库，不在实际演示库中写入验收数据。

```sh
prototype/.venv/bin/python -m unittest discover -s prototype -p 'test_*.py'
node prototype/test_public_tools.mjs
node prototype/test_workspaces.mjs
prototype/.venv/bin/python prototype/server.py --host 127.0.0.1 --port 5197 --db /tmp/portal-admin-qa.sqlite3
DEMO_QA_URL=http://127.0.0.1:5197 prototype/.venv/bin/python prototype/check_portal_admin_browser.py
```

浏览器结果保存至 `prototype/reports/portal-admin-browser-checks.json`；截图位于 `prototype/reports/screenshots/portal-admin-*.png`。

验收结果：142 项 Python 测试、前端空间工具和工作台脚本通过；18 组桌面/手机页面检查无横向溢出、无浏览器异常。浏览器实际完成工具发布下架、附件上传下载、注册审核及企业角色开通、密钥申请审核领取与接口调用/停用拦截、日志检索、配置保存及数据库备份还原。CPU/内存使用 psutil 采集，当前本机已验证实际数值。

本地 5190 服务已加载新版；升级前创建数据库备份，升级后核对原有 14 项资源、7 个用户、2 份申请、8 篇资讯均保留。验收数据仅写入独立测试库。

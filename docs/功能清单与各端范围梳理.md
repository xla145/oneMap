## 核心结论与术语

清单中的“统一门户（服务端）”包含首页布局、个人中心、地图预览、办事查询等页面，因此应理解为“面向用户提供服务的门户”，不能直接解释成 Java、数据库或 API 所在的技术后端。

“门户”是系统入口与功能集合的称呼；第 1 章和第 2 章都属于门户。“后台”主要指管理员使用的管理界面；“后端”指支撑页面和系统集成的程序与服务。三者不是同一维度的分类。

| 建议统一名称 | 原文对应 | 主要使用者 | 范围说明 |
|---|---|---|---|
| 内部业务门户 | 第 1 章：统一门户（管理端） | 根据功能推断，主要为自然资源部门业务人员、资源管理人员和管理员 | 业务入口、一张图、资源与工具使用、任务协同、数据治理、平台管理 |
| 对外服务门户 | 第 2 章中面向使用者的功能，主要在 2.1～2.6 | 照片正文明确面向社会公众、企事业单位、科研院所；清单包含普通用户、企业用户等角色 | 数据获取、工具使用、办事查询、资讯下载、专题浏览 |
| 服务门户管理后台 | 2.7，以及 2.2～2.6 中的管理操作 | 门户运营人员、审核人员、系统管理员 | 管理数据、工具、用户、内容、审核、安全与运行状态 |
| 后端接口与服务 | 跨越上述各章，未按技术层单独成章 | 由各类页面、外部系统及开发者调用 | 登录鉴权、数据读写、审批、文件、GIS、API、消息、集成等 |

补充照片正文明确：该服务门户是自治区自然资源部门对外的统一服务窗口，依托政务云互联网区，面向社会公众、企事业单位、科研院所。因此，对外门户的互联网服务定位已有正文依据。具体公开数据范围、登录要求、后台访问网络及与内部系统的对接部署仍需明确。

## 整体范围

原清单包含四大部分，不能全部归入一个网站后台。

| 原文章节 | 内容 | 本文理解 |
|---|---|---|
| 1 统一门户（管理端） | 综合集成、资源中心、工具中心、应用中心、智能中心、运营中心 | 内部业务门户，兼有业务使用和管理配置功能 |
| 2 统一门户（服务端） | 门户首页、数据服务、能力服务、办事服务、资讯下载中心、大美内蒙古、后台管理系统 | 服务门户及其管理后台 |
| 3 五大应用场景建设 | 自然资源大管家、国土空间规划、耕地保护与国土绿化、要素保障、矿业权审批等 | 专项业务应用，不能仅按门户导航入口核算 |
| 4 开发统一掌上自然资源集成应用 | 蒙政通“掌上管”、蒙速办“掌上办” | 移动端集成与移动业务功能 |

以上是业务范围划分，不意味着必须建设四个独立代码仓库或部署四套系统。

## 内部业务门户

对应第 1 章“统一门户（管理端）”。它是一套内部业务平台，不能直接与 2.7“后台管理系统”画等号。

| 模块 | 原文功能概括 | 页面和能力性质 |
|---|---|---|
| 1.1 综合集成 | 一张图成果、数字资源、工作任务、门户通用功能、工作台配置、现有系统集成、国家级对接、纵向贯通、横向联动 | 业务首页、地图与工作台，包含配置页面和系统对接 |
| 1.2 资源中心 | 库表与图层检索浏览、申请车、我的资源、使用申请审核 | 查询申请面向业务使用者；审核面向审核人员 |
| 1.3 工具中心 | 空间计算工具接口、工具浏览与申请、上下架、权限管控 | 工具使用页面、工具管理页面及计算接口 |
| 1.4 应用中心 | 场景构建、审批流程构建、统一用户管理、单点登录、服务网关、消息总线、应用上下架 | 应用构建和管理界面，以及平台公共服务 |
| 1.5 智能中心 | 智能资源检索助手、AI 配套工具、提示词模板管理 | 智能交互页面、配置管理与 AI 支撑能力 |

内部业务门户还包含管理功能，例如 1.1.4.3 门户配置、1.2.5 使用申请审核、1.3.4 工具上下架、1.3.5 工具权限、1.4.7 应用上下架。这些应归入内部平台相应角色的管理范围，不能仅因为名称里有“管理”就移到 2.7。

### 六大对外栏目及页面内容

以下为照片正文要求的整理，页面拆分方式属于建议，不代表原文规定必须有相同数量的独立页面。

#### 2.1 门户首页

首页是服务端总入口，集信息汇聚、服务导航、资源展示于一体。

| 区域 | 正文明确内容 | 建议页面承载 |
|---|---|---|
| 顶部导航 | 首页、数据服务、能力服务、办事服务、资讯下载、壮美内蒙古 | 六个一级栏目入口 |
| 中部快捷入口 | 地图浏览、数据申请、常用工具、办事服务 | 直接进入对应功能的快捷操作 |
| 动态展示 | 政策法规滚动通知、热门数据推荐 | 通知和推荐资源展示区 |
| 全局搜索 | 快速检索数据、工具或资讯 | 首页搜索框及分类结果展示 |

名称差异：照片首页导航写“壮美内蒙古”，同组照片 5.4.1.2.6 标题和功能清单 2.6 均写“大美内蒙古”。本文暂沿用“大美内蒙古”，实际导航文案待统一。个人中心、角色化视图、响应式框架等继续按原清单 2.1 执行，不能因照片概述未提及而遗漏。

#### 2.2 数据服务

定位为权威自然资源数据的“超市”，重点覆盖“找到数据—了解数据—预览数据—申请—审核—获取”的完整流程。

1. 按自治区实际需求主题分类展示数据目录，支持关键词检索与筛选。
2. 数据详情展示来源、更新日期、空间范围、使用限制等元数据。
3. 提供地图在线预览，帮助用户了解空间数据内容。
4. 用户填写用途和期限，在线发起数据申请。
5. 管理员在后台审核，通过后自动开放下载或 API 授权。
6. 推荐热门数据，提供标准 OGC 地图服务及 REST API，供开发者调用。

页面建议：目录列表、数据详情与地图预览、申请表单、申请结果/授权信息。申请记录、密钥管理、裁剪下载和统计看板的更细要求沿用原清单。正文没有说明全部数据都可免登录或免审核获取。

#### 2.3 能力服务

通过在线空间分析与合规性审查降低用户技术门槛，服务企业、科研机构和开发者。

| 类别 | 正文明确功能 | 交互说明 |
|---|---|---|
| 基础工具 | 缓冲区分析、面积量算、坐标转换、叠加分析 | 提供在线使用入口；具体参数沿用清单并在设计时细化 |
| 高级工具 | 项目选址、合规性审查 | 用户上传地块坐标或规划数据，系统自动分析是否符合生态红线、永久基本农田等管控要求 |
| 共享模型 | 国家级和自治区级共享模型 | 在工具市场展示，支持在线体验 |

照片补充了“规划数据”作为输入的表述，应与清单中的“地块坐标或范围”合并核对输入类型。报告输出、API 调用、教程、版本和权限管理继续保留清单要求；具体格式、算法规则、计算资源和数据更新机制尚需细化。

#### 2.4 办事服务

整合自然资源领域面向公众和企业的线上服务入口，实现“一窗办事”。

| 服务 | 正文明确的查询或交互 |
|---|---|
| 不动产登记信息查询 | 权属、面积、抵押状态 |
| 用地审批进度 | 输入项目编号，实时跟踪审批进度 |
| 矿业权信息查询 | 基本信息与有效期 |
| 国土空间规划公示 | 草案、成果、修改方案展示，接受公众意见反馈 |
| 地价查询 | 基准地价查询；监测地价仍按原清单保留 |
| 办事指南 | 材料清单、办理流程、咨询电话；清单另含办理时限 |

“办事服务”在这些正文中主要体现为入口整合、查询、公示和反馈，不能直接扩展解释为在门户重建所有审批业务。实际对接方式按清单与接口条件逐项确定。

#### 2.5 资讯下载中心

- 政策法规：分类发布国家与自治区自然资源法律、规章、规范性文件。
- 行业动态：及时更新工作新闻、通知公告。
- 技术标准：提供数据规范、技术规程等文档下载。
- 使用方式：用户可免费下载使用，为日常工作与学习研究提供支持。

“免费”是本栏目资源使用的正文描述，不等于所有数据服务免费或所有文件匿名可下载。培训资源、视频、操作手册、全文检索和推荐继续按原清单保留。

| 国土空间规划格局 | 2.6.2 国土空间规划专题 |

## 服务门户管理后台

### 图片正文补充确认

照片 5.4.1.2.7“后台管理”明确后台为该平台稳定运行提供管理支撑，列出五类能力：数据管理、工具管理、用户管理、内容管理、日志审计。这进一步确认：这里的后台是对外服务门户的管理侧，与第 1 章内部业务门户不能直接等同。

照片明确了用户注册审核、角色权限分配及访问分析；数据申请在后台审核；资讯、政策和下载资源由后台发布维护。清单 2.7 另列的安全配置、系统监控、统计分析仍保留，不能因这段正文只概括五类模块就删减。

照片没有指定后台菜单布局、独立域名或访问网络，也没有证明内部和对外门户必须共用一套后台，这些仍是实施层面的待明确事项。

来源：IMG_8421.HEIC，第 198 页。

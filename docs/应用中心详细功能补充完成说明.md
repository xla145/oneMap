## 3. 新增本地接口

入口为 `POST /api/action`，请求体为 `{"action":"动作名","payload":{...}}`，沿用原型演示身份头。权限、修订冲突和错误仍由服务端校验。

| 动作 | 主要参数与语义 |
| --- | --- |
| `platform.compliance` | id、rev、compliance、note；记录合规核查结果 |
| `platform.supervise` | caseId、note；新建督办。解除时另带 id、rev |
| `platform.dashboard` | modules；仅维护当前用户首页 |
| `platform.flowCheck` | id；返回节点、检查结果和发布依赖提示 |
| `platform.clientVerify` | appKey、appSecret；验证本地客户端凭据，不签发SSO令牌 |
| `platform.ingestEvent` | sourceId、eventId、eventType、topic、tags、data；本地管理员接入演练，校验Schema及去重 |
| `platform.pull` | channelId、limit；拉取当前身份消息，管理员可明确指定演示 userId |
| `platform.ack` | deliveryId、receiptToken、outcome（成功/失败）、note；租约内提交业务回执 |

`platform.caseCreate` 增加 projectId/projectType；`platform.sceneRuntime` 支持 template + preview；原有保存接口扩展图片和消息配置字段。

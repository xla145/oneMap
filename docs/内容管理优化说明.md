# 内容管理优化说明

更新日期：2026-09-16。适用范围：`prototype/` 本地门户原型。

## 需求依据与问题

对照《统一门户服务端_功能清单_附表识别》2.4.6（办事指南）、2.4.7（咨询留言）、2.6.6（专题维护）、2.7.4（内容发布、分类、编辑、删除）。需求原文保持不变，本说明记录实现调整和待补齐项。

原“公共门户运营”页面重复左侧栏目导航，且导航继承全局纵向布局，造成切换入口占用大块空间。卡片列表不便检索，草稿状态无法明确表示线上是否仍有旧版本；专题和办事服务缺少预览、删除入口；回复弹窗没有展示原问题与历史记录；排序为 0 时编辑框错误回填为 1。

## 页面与操作调整

全部入口保留在 **门户管理 → 内容管理**，原查询参数地址兼容。

| 页面 | 调整 |
| --- | --- |
| 首页配置 | 独立页面标题；展示首页标题、介绍、推荐数据、线上版本与草稿状态；编辑、文字预览、发布。未选择推荐数据时继续自动展示最新数据。 |
| 办事服务管理 | 表格列表；名称/分类搜索、状态筛选、每页 10 条；新增、编辑、内容预览、发布、下架、删除；新增办理流程、材料清单、办理时限、咨询电话，发布后在前台事项详情展示。 |
| 大美内蒙古专题 | 同样的列表、筛选及生命周期操作；保留封面、分节、媒体资料和关联数据配置；分节与媒体编辑区域支持折叠，减少长表单。 |
| 咨询与公众意见 | 按标题、事项、提交人、编号搜索，按状态筛选并分页；受理弹窗展示原问题、提交时间、历史处理人、回复内容和时间；已回复记录可补充回复，不能回退至处理中。 |
| 资讯与政策、下载资料 | 保留现有独立入口和附件管理流程，本次不改动其编辑器。 |

不再重复四栏内容导航。未知 `tab` 自动回到专题管理。列表在窄屏内横向滚动，保留左侧菜单折叠及当前栏目定位。

## 发布与删除规则

- 草稿保存不更新线上快照。已有线上版本时显示“线上 vN · 有未发布修改”；下架后编辑仍显示“前台不可见”。
- 已发布且没有新草稿的内容不提供重复发布按钮，接口也拒绝重复发布。
- 新草稿、已下架内容可以删除；线上内容必须先下架。删除弹窗要求再次确认，接口检查管理员权限与记录修订号。
- 首页配置不允许删除或下架。删除办事服务保留历史咨询和回复，便于追溯。
- 排序 0 正确保留；已有数据无需重建，新指南字段按需补充。
- 预览用于审核已保存的文本、分节、指南字段及外部资料链接，不等同于完整前台地图/封面渲染。

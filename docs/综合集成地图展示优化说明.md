# 综合集成地图展示优化说明

更新日期：2026-09-16。依据：[正文与附表合并分析](../img/运营中心/综合集成_正文与附表合并分析.md)中空间图层集成要求（附表1.1.1.1）。本文记录实际优化，不将二维原型视为完整三维平台。

访问：[一张图成果工作区](http://127.0.0.1:5190/#/admin/integration-results)。进入后自动加载首个可访问的已上架场景；切换场景时重新取得发布配置和当前权限。

## 页面归属纠正

正文5.4.1.1.1.1将成果集成定位为“面向管理层用户”的成果展示、查询分析与综合研判入口。按用户明确的产品归属要求，本工作区位于后台“综合集成 → 一张图成果”，使用后台菜单、面包屑与访问权限，不挂在公众门户页面。旧门户地址仅跳转至后台地址，再检查管理权限；门户不再提供该成果工作区入口。

地图展示继续读取已发布场景；后台展示与应用中心的场景编辑/发布是两个操作。当前沿用综合集成的平台管理员权限，后续可按实际岗位配置管理层授权。

## 1. 原有问题与本轮调整

| 原有问题 | 已实现的调整 |
| --- | --- |
| 进入地图页后空白，需要手动加载 | 自动加载，提供加载中、加载失败、无可访问场景及重新加载状态 |
| 左侧图层平铺，不便查找 | 图层关键词检索、按资源分类或提供部门分组、组内数量、匹配/总数；检索不偷偷关闭正在显示的图层 |
| 图层颜色不易区分，缺少图例 | 已启用图层使用对应颜色图例，透明度可调；查询范围和命中结果单独标识 |
| 只能手动缩放寻找示例图斑 | 每个授权图层可定位其要素范围；无要素时给出说明 |
| 缺少区市县定位操作 | 自治区全域、12个盟市、103个旗县选择；更换盟市时清空旧旗县并重新过滤候选项 |
| 查询结果只能阅读文字 | 结果逐项定位并打开属性，可返回列表及定位全部结果；未命中与失败分别提示 |
| 单点/穿透需要输入坐标 | 可选择点击地图进行单点或穿透查询；坐标查询仍保留，并默认使用当前视图中心 |
| 周边查询看不到实际范围 | 服务端返回实际查询几何，显示点位或缓冲范围；支持拉框/多边形范围与历史重放定位 |
| 旧结果可能干扰下一次查看 | 清除结果同时清除范围、量算和高亮；关闭图层即清除旧结果，迟到查询响应不再回填 |
| 地图区域空间不足 | 可放大工作区、Esc退出；移动端改为上下布局，修复地图容器内边距导致底部控件被裁切的问题 |
| 缺少方向和位置反馈 | 指北复位、当前中心经纬度/缩放级别/旋转角度；原有全景、缩放、底图切换、面积量算继续复用 |
| 快速操作可能混入旧场景 | 场景加载和查询分别校验请求序号；离开页面销毁地图，重复加载不叠加画布；绘制时Esc先取消绘制 |

未授权但目录可见的图层显示“需申请”，不展示几何与要素数量，不能启用或定位；提供原资源详情/申请入口。不可见目录资源仍由运行时接口过滤。

## 2. 页面操作流程

1. 进入成果工作区，自动加载已发布二维场景；查看顶部版本、图层数和当前角色查询面积上限。
2. 搜索或分组查找图层，调整显示和透明度，点击“定位图层”查看图斑；也可选自治区、盟市、旗县定位。
3. 默认点击图斑查看属性；切换为单点/穿透后直接点击地图查询，或使用拉框、多边形、坐标/周边查询。
4. 在右侧查询结果中点选一项定位与查看属性；“返回查询列表”保留同一查询结果，“定位全部结果”适配所有命中范围。
5. 使用“清除结果”开始新一轮查看；展开“我的查询历史”可重新执行，场景与图层权限重新校验。

检索词和目录分组只影响列表呈现；查询以全部已启用的授权图层为准。查询范围面积由服务端计算，超过已发布角色阈值时拒绝。业务属性中的示例面积与几何量算面积明确区分。

## 3. 目前仍缺的地图能力

| 剩余项 | 当前边界 | 后续设计/数据条件 |
| --- | --- | --- |
| 正式图层服务 | 当前使用场景发布配置及虚构示例图斑；在线底图失败会提示并切换本地行政区底图 | 正式服务地址、访问凭据、坐标基准、数据更新机制、图例/样式与服务异常处理 |
| 主题/部门/盟市/热点四维目录 | 本轮实现关键词、资源分类/来源部门分组与行政区定位；没有完整四维图层目录树 | 建立真实图层元数据、热点定义、目录归属和一致计数，不能把行政区定位下拉框当成盟市图层分类 |
| 图层顺序与复杂样式 | 使用发布配置顺序和本轮颜色区分；无交互式层级排序与分级渲染编辑 | 可调整图层叠加顺序，支持分类/分段符号、标签、图例联动与保存策略 |
| 地图收藏与分享 | 已有查询历史；不等于命名视角收藏、共享地图或地图导出 | 视角、图层组合、范围、所有者、可见性；恢复时重新检查权限，导出明确数据许可及比例尺 |
| 三维交互与七类分析 | 仍为二维OpenLayers；没有三维漫游、鸟瞰、飞行及七类分析 | 高程、地形、建筑模型、统一坐标/高程基准、三维引擎与可验证算法 |
| 时序与正式八专题 | 尚无时间轴、同期/跨期对比或正式八专题结果 | 同主题多期数据关联、版本和时间元数据、专题规则、无数据状态与结果钻取 |
| 完整量测与绘图 | 已有面积量算、拉框/多边形查询；尚无完整距离量测、标注编辑与成果打印 | 量测单位/精度、编辑撤销、绘制对象管理、输出与留痕 |
| 业务监测联动 | 当前图层数和启用状态反映本次工作区；不等于完整图层运行监测 | 接入进度、实际容量、响应耗时、调用失败、数据时效与归口责任人 |

行政区边界采用现有演示数据，不能作为法定边界或测绘依据。浏览器内图层过滤与显示控制不能替代服务端数据权限。

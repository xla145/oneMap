# 智能中心跨模块关联完善

日期：2026-09-16。实现范围：现有 `prototype/` 的管理界面与关联分析，复用原有资源、知识、智能体、应用等记录。

## 页面与行为

| 入口 | 行为 |
| --- | --- |
| `/#/admin/metadata-annotation` | 按资源名称、来源、同义词检索；直接打开同一资源的 AI 语义或字段标注页。保存沿用资源草稿和发布流程，运营中心立即可见，不创建重复资产。 |
| `/#/admin/intelligence-links?asset=agents%3Aa1` | 选择对象，查看其使用的对象、被引用位置和间接关联；显示所属中心、当前线上版本、缺失对象；可进入所属模块或打开对象编辑/应用详情。 |
| `/#/admin/intelligence-evaluations` | 查看已有评测报告，选择智能体运行线上资产与当前草稿资产对比。智能体列表、关联页和发布确认均可进入评测。 |

关联分析通过 `view=online` 与 `view=draft` 区分线上快照和当前编辑配置，刷新、分享链接会保留对象与范围。停用对象不再产生线上出向关系；其他对象对其保存的显式引用仍会展示，便于识别异常依赖。

覆盖资源及其元数据模板、枚举字典、关联知识与资源；智能体资产范围、协作智能体、地图；指标数据源、复合指标和知识依据；语料业务来源、反馈样例；工具与内部资源绑定；应用目标、地图控件、应用绑定场景快照、业务事项与流程知识依据。

“全部已发布且用户有权访问”的配置显示为动态范围。相关行属于潜在关联，实际是否使用取决于调用用户权限、查询和执行路径。工具资源关联不等同于工具执行接口已接通。

## 跨模块入口与发布核对

- 智能体、知识、指标、语料和资源列表增加“关联与影响”。应用注册、场景/事项/流程操作和门户工具管理提供反向入口。
- 资源关联页可进入共享目录与授权台账；知识关联页可进入门户资讯；智能体关联页可进入综合集成和统一用户权限管理。
- 资产编辑及发布/停用确认显示线上显式、动态与间接关联数量；智能体显示最近评测记录，提示变更后重新评测。
- AI 索引更新/退出确认可查看知识引用影响；门户发布和 AI 检索继续独立操作。
- AI 知识库统计、筛选和行状态统一为“检索已启用、未纳入检索、索引待更新”，不再用门户或文档发布数量替代检索数量。
- 关联与标注入口沿用平台管理员权限，没有扩大其他岗位的数据读取范围。

## 边界

关联分析基于当前可读取的结构化配置，不是实际调用链或生产血缘扫描；不解析任意 SQL、外部系统和历史办件内部的所有依赖。场景来源与应用已绑定快照分别提示，间接关联用于人工核对，不能据此断言所有应用都会故障。

本次不改变运行时授权、发布语义、数据交付或工具执行机制，不自动级联下架。评测仍使用现有本地规则，并明确包含关联资产草稿变化；未新增生产模型接入或通用工具编排。

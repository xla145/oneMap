# 智能中心原型需求覆盖核查

核查日期：2026-09-14  
需求基准：[图片内容整理.md](图片内容整理.md)  
核查对象：`prototype/` 当前前台、后台、服务端与本地演示流程。

## 一、结论

**尚未全部覆盖。检索助手、智能体广场及五类配套工具均有模块入口，但部分需求只有配置表单，部分运行能力采用简化规则，还有明确缺失的交互。**

当前版本可以演示“检索资源—查看详情—批量申请—模拟审批—授权使用”主线，以及资产编辑发布、知识引用、基础指标试算、反馈转样例等流程；不能据此认定完整需求已经实现。

本报告区分三种状态：

- **已覆盖（原型层面）**：有对应界面和本地可操作流程，不代表生产服务已接通。
- **部分覆盖**：已有部分字段或流程，但需求中的关键行为尚未体现。
- **未覆盖**：未找到对应业务交互或执行能力。

不以菜单数量或已有测试通过数量计算功能覆盖率。原需求粒度不一致，直接计算百分比会造成误导。

## 四、已复核的具体问题

以下行为核验使用 `seed()` 创建独立内存数据，调用现有服务函数；未修改运行中 SQLite 演示数据。浏览器仅打开页面与导入弹窗，没有提交修改。

| 核验 | 实际结果 | 代码依据 |
| --- | --- | --- |
| 发布修改后的提示词，再问相同非标准样例问题 | 回答未变化；代码仅消费精确匹配的问答样例，未使用提示词正文 | `prototype/server.py`：`chat()`，166 行起 |
| 将检索助手步骤改成“展示结果 → 识别条件”并发布 | 相同问题仍返回相同资源，步骤未驱动执行 | `prototype/server.py`：`chat()`；`prototype/app.js`：935 行 |
| 给字段添加独有同义词，再检索该词 | 返回空；把同一词配置到资源级同义词后返回 `r1` | `prototype/server.py`：`chat()` 内 `score()` |
| 将指标关联字段改为不存在的字段，再试算 | 结果仍是 400；实际读取手填的 `values` | `prototype/server.py`：89 行、112 行 |
| 查询“包头市地灾”，新建会话询问“继续上次任务” | 新会话恢复为“全区 / 耕地保护”，未接续之前主题和区域 | `prototype/server.py`：166 行、230 行 |
| 浏览器打开知识导入弹窗 | 文件输入 `multiple=false`，仅接受 `.txt,.md` | `prototype/app.js`：1391 行、1630 行 |
| 保存 10001 字中文正文（UTF-8 约 30KB） | 后台报“文本格式或长度不正确”；页面却称支持最大 200KB | `prototype/server.py`：85 行、151 行；`prototype/app.js`：1394 行 |

另外，个人偏好页面在“历史摘要”下提示“用于新会话的默认偏好”，但新会话实际只读取区域和业务领域等结构化字段，没有读取摘要文本。应使说明与行为一致。

单次输出相同本身不足以判断配置无效；上述结论同时依据执行代码路径，确认相关配置未被消费。

## 五、建议补齐顺序

### 第一批：让完整 Demo 的关键需求可操作

1. **配置与运行联动**：让提示词、编排步骤、字段同义词、元数据模板产生可观察效果；增加执行节点状态和输入输出。可以继续使用本地规则模拟。
2. **知识生产流程**：批量导入、清洗与标准化确认、切片处理状态、向量化演示状态，以及可编辑的实体关系图；统一文件与正文长度限制。
3. **指标分析流程**：从本地示例表字段取数，校验字段，增加至少一个复合指标及跨期、区域对比案例。
4. **语料质量流程**：维护评测集、预期答案与操作序列，展示版本回归结果；补充 NL2API 调用演示。微调先覆盖数据准备与导出即可。
5. **记忆接力流程**：补技能等级、多轮摘要、记忆来源和跨会话继续任务，让新会话真正使用已保存背景。
6. **元数据细节**：补字典项值、资源子类型、明确的表关系与图层数据源映射。
7. **统一管控与开放演示**：明确各类资产权限，提供可查看和试调用的接口契约，并补反馈更新标注与记忆的处理路径。

建议每项至少提供一个可复现的“后台配置—前台使用—结果变化”验收场景，避免只增加页面。

### 第二批：真实系统集成

真实大模型和向量服务、资源中心审批接口、生产数据源、正式 GIS 与工具算法、外部智能体、统一身份与生产权限等属于集成工作。原型阶段可以模拟，但页面应清楚体现调用过程和结果，不能把模拟标记为真实接入。

## 六、核查范围与限制

本次依据指定的原始需求全文，结合页面、服务端与前端代码进行核查，并针对高风险差异开展浏览器检查和隔离行为实验。没有重新执行所有页面的全量回归，也未验证任何真实外部系统。

已有验证记录中的领域测试和页面检查证明选定流程及布局可用，不等于原始需求全覆盖。此前“完整智能中心”的描述适合理解为模块结构完整；若理解为全部功能已实现，则表述过宽。

本次仅新增核查文档，未修改原型实现。

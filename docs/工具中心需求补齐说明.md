# 工具中心需求补齐说明

日期：2026-09-16。

依据：`img/工具中心/工具中心.md`、`img/all/工具中心功能清单_附表2.1.md`。本次补充现有本地原型，不连接生产 GIS 或外部工具服务器。

## 入口与操作

- 前台：`/#/front/capabilities`，统一浏览工具组件和共享工具资源。
- 卡片“直接使用 / 开始使用”为可点击入口，打开 `?view=use` 工具操作页；“查看详情”保留接口文档入口。外部工具调用已登记入口，缺少入口的共享工具显示“入口待配置”。
- 后台：`/#/admin/center-tools`，注册、配置、提交审核、审核发布、下架和接口试运行。
- 后台：`/#/admin/portal-tools`，维护截图、接口资料、共享目录和工具使用方式。
- 两个工具管理入口都可打开“类型与模块权限”。
- 检查、查询、入库和编辑四类组件可通过“登记内部组件模板”创建草稿，再按需要配置角色、审核和发布；不会自动绕过审核上线。

## 需求覆盖

| 需求 | 本次实现 |
| --- | --- |
| 目录查询 | 共享目录、部门、地市及工具类型筛选；显示各分组工具数量。关联资源优先使用资源中心维护的共享编目、数源单位和所在地区。 |
| 搜索统计与排序 | 按名称、介绍、分类、单位、接口类型模糊搜索，显示匹配数量；最新按发布时间排序，最热按历史申请次数排序。 |
| 工具卡片 | 缩略图、接口类型、名称、数源单位、上架时间、申请次数、详情和申请操作；未上传截图时标识为功能示意图。 |
| 工具详情 | 类型、功能模块、发布单位、提供方、发布时间、版本、介绍、参数表、请求示例、返回说明与示例、在线测试及结果下载。外部工具资料可在后台维护。 |
| 使用申请 | 卡片支持加入申请车和直接打开申请表；复用资源中心申请、审核、授权期限及撤销。公开组件可直接使用；选择“申请授权”时必须关联工具资源。 |
| 上架注册 | 补充截图上传、发布单位、所在地区、共享目录、接口类型、功能模块、参数定义与请求 / 返回示例。 |
| 上架审核与下架 | 沿用配置审核后发布流程；新增配置字段和截图纳入审核签名，配置变更后需重新审核。历史发布版本继续可用，下架拦截后续调用。 |
| 权限 | 单工具角色、关联资源授权，以及“角色 × 工具类型 × 功能模块”附加限制共同生效；后端调用重新校验，不能仅通过直接请求绕过页面限制。 |
| 叠加分析 | 保留相交、差集、融合、面缓冲，在线接口支持 WKT、坐标文本、GeoJSON 与声明坐标系。 |
| 坐标转换 | 支持 EPSG:4326、3857、4490，以及 CGCS2000 的 EPSG:4491—4554 投影定义；支持单点、WKT、GeoJSON 和界址点文本。 |
| 空间检查 | 成图、拓扑、自相交、重复点、行政区越界和共边关系。行政区边界与相邻图形由请求提供，缺少依据时明确返回“未检查”。 |
| 空间入库 | 图形转换并写入指定资源对应的本地工作图层，保留业务属性，校验唯一 ID 与图层版本。 |
| 面积核算 | 接收 WKT、坐标文本、GeoJSON，多边形与孔洞沿用既有面积计算引擎，返回平方米。 |
| 空间编辑 | 按 ID 或唯一名称更新、删除；名称重复时要求使用 ID；仅改几何时保留原属性，版本不匹配拒绝写入。 |
| 空间查询 | 支持关键词、行政区字段、坐标定位组合查询，返回要素列表、结果总数和最新图层版本。 |

## 输入与执行范围

在线接口为 `POST /api/action`，请求包含 `action: "portal.toolRun"` 和 `payload: {id, payload}`。页面“请求 JSON”编辑的是内层组件参数。

界址点 TXT / CSV 接受每行 `x,y` 或 `点号,x,y`，不带表头。页面支持导入 `.wkt`、`.txt`、`.csv`、`.json`、`.geojson`。经纬度采用 X=经度、Y=纬度，投影坐标采用 X=东坐标、Y=北坐标。地方专用界址点格式、七参数拟合和控制点校正不在此实现范围内。CGCS2000 内部的投影转换按 EPSG 定义计算；CGCS2000 与 WGS84 之间使用 PROJ 近似基准转换，结果通过 `approximateDatum`、`note` 或 `coordinateNote` 明确标识，不作为测绘成果。

空间检查的行政区边界与相邻图形必须与被检查图形使用同一坐标系；共边是关系结果，不自动判定为错误。行政区查询匹配工作图层要素属性中的 `region`。

入库、查询、编辑仅作用于持久化的本地工作图层。写操作限管理员，查询同时校验目标资源授权；生产空间数据库和外部工具仍需实际接入。外部接口未配置时显示缺少入口，不返回模拟成功结果。

参数定义使用 JSON 数组，每项包含 `name`、`type`、`required`、`description` 四个文本字段；留空时使用组件默认说明。截图支持 PNG、JPEG、WebP，最大 2MB，保存时校验格式。历史申请次数统计包含曾提交的申请，不等同于调用次数。

## 验证

- `test_tool_center`、`test_centers`、`test_portal_management`、`test_public_portal`：相关后端用例验证投影往返、输入校验、检查结果、查询与编辑、授权申请和撤销、权限拦截、审核签名及既有流程。
- `check_tool_center_browser.py`：在独立 QA 数据库验证搜索、CGCS2000 在线测试、注册与截图上传、审核发布、目录筛选、面积计算、权限配置和共享申请。
- 直接使用回归从卡片点击进入，分别以管理员、普通用户验证坐标转换、面积量算、点缓冲区、叠加分析和合规核查的计算结果，避免只测试详情页而遗漏卡片入口。
- 桌面 1440px、移动 390px 下检查目录、工具详情和后台台账，无页面横向溢出；截图位于 `prototype/screenshots/tool-center-1440.png` 与 `tool-center-390.png`。

运行浏览器检查前设置 `DEMO_QA_URL`，指向独立测试服务；脚本会创建测试工具与申请。

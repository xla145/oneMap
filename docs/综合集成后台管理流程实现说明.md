# 综合集成后台管理流程实现说明

日期：2026-09-16。本轮落实后台评审中优先级最高的三项：导航与成果使用权限、待办与接入异常管理、可下钻的运行总览。

入口：http://127.0.0.1:5190/#/admin/center-integration?tab=overview

## 1. 后台组织

保留“一张图成果”在后台。原综合集成管理页的十个平级标签改为左侧分组，各页面使用独立地址；刷新、浏览器前进后退和链接分享均保留页面及入口筛选条件。

| 分组 | 页面 |
| --- | --- |
| 总览与成果使用 | 运行总览、一张图成果 |
| 门户与成果配置 | 内部门户展示、公告通知、成果编排 |
| 系统接入 | 内部系统、国家对接、纵向交换、横向联动、接入计划、统一登录接入 |
| 任务协同 | 待办同步、办理核对、消息总线 |
| 运行监测 | 异常处理、使用统计 |
| 权限与租户 | 成果使用授权、三级租户 |

“门户运营”的首页配置重命名为“公众门户首页配置”，与综合集成的“内部门户展示”区分。面包屑和页面标题对应具体管理页。移动端分组内导航可横向滚动，表格保留横向滚动容器。

## 2. 管理首页与接入流程

运行总览的主要卡片改为：待完善接入配置、待处理同步失败、待核对办理状态、待发布内容。点击卡片进入相同统计口径的列表。资源数量降为辅助概况，按类型进入成果编排。

- 接入完整度来自九系统的入口、必要认证客户端及其有效状态，不声称已经外部联通。
- 首页展示配置缺失、负责人、最近同步批次和接入计划。
- 系统详情关联访问入口、单点登录客户端、待办范围、负责人、检查时间和管理入口。
- 接入计划复用既有服务端计划能力，补齐维护界面：对象、责任人、部门、计划日期、阶段、进展、人工验收依据。
- 异常处理集中展示接入配置问题、未恢复待办同步失败、目录交换失败历史；各项可回到相应详情处置。

## 3. 待办同步与人工核对

两个已有待办来源分别独立配置接收人和状态映射。界面以可增删的映射行维护，无须编辑映射 JSON；来源任务批量导入仍使用 JSON 数组。

导入流程：

1. 选择来源系统，导入带正整数来源版本的任务。
2. 按原系统字段映射读取数据，再应用人员和状态映射。
3. 整批验证接收人、状态、日期、入口、重复标识和来源版本；任一条失败时不写入任何任务。
4. 保留批次、来源数据、错误行号及原因、映射版本、新增/更新/跳过数量。
5. 相同版本相同内容再次导入只跳过；旧版本及相同版本不同内容拒绝覆盖。
6. 修正映射后从失败批次重试；新批次关联原批次，成功后原失败从待处理列表移出，历史记录保留。
7. 源数据撤回或已经另批修正时，可填写依据人工归档；另批修正必须关联同一来源系统的成功批次。人工归档不把失败改成成功。

已进入版本同步的任务不能再通过旧版无版本导入覆盖，避免绕过版本保护。来源任务标识按系统隔离。

办理核对记录当前本地状态、人工查得的来源状态、依据、操作人和时间；不一致时明确标识，不擅自改动来源状态。任务版本更新后旧核对记录只保留为历史，新版本重新进入待核对。旧版本的核对提交会被拒绝。

**边界：本轮实现本地同步与人工核对流程，没有接入外部任务接口、自动调度和真实办理回传。** 未配置办理入口的任务仍不能直接跳转业务办理。

## 4. 成果使用权限

平台管理员可对已有用户分别授予“成果查看”“空间查询分析”；分析依赖查看权限。

- 授权用户可进入后台成果工作区，不因此获得门户发布、系统接入、租户或其他管理权限。
- 仅查看用户可浏览授权场景和图层属性，空间查询、历史重放和绘制分析入口禁用。
- 服务端空间查询再次验证分析权限；隐藏按钮不能替代后端校验。
- 成果使用授权不替代资源使用许可、行政区范围和面积阈值。
- 撤回查看授权后，业务身份的后台访问被拒绝；具有其他后台岗位的身份仍保留其原岗位入口。
- 授权包含版本检查与操作历史；演示身份切换支持已授权成果用户，避免按旧业务角色规则跳回门户。

身份仍沿用原型演示机制，不代表生产统一认证。

## 5. 数据与兼容性

在现有 integration 状态下增量保存成果授权、任务适配、同步批次、人工核对记录；复用 centers 的系统和任务主记录，没有另建同名系统。已有资源、应用、用户、公告、租户及授权记录保持原结构。

原有综合集成地址默认进入运行总览；个人工作台标签和成果地图标签继续保留。原有浏览器回归脚本同步适配新的后台地址。

本轮未实现完整三维、正式专题及时序数据、全平台租户化、跨节点真实通信，也未将门户展示改造成完整可视化页面编辑器；这些仍属于后续需求范围。

## 6. 验证

- 后端覆盖成果授权与撤权、越权拒绝、资源权限独立、同步幂等、旧版本/冲突版本拒绝、整批原子性、失败重试、人工核对失效、人工归档及映射版本冲突。
- 新浏览器回归覆盖全部15个管理页面、总览下钻、刷新保持、系统到待办跳转、失败后补映射重试、重复导入、状态不一致、接入计划保存、实际身份切换、查看权限、撤权和手机布局。
- 原综合集成浏览器回归通过：门户发布、个人配置持久化、二维查询、租户成员与空间隔离、移动端布局。

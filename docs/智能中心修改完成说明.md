## 本轮结果

先形成修改方案，再完成代码修改和验证。原型已更新到原有 5190 服务，现有数据采用兼容升级。

本轮补齐的是可运行的本地 Demo 流程，不将规则检索、本地特征向量或模拟审批称为生产 AI 能力。原始核查文档保留，作为修改前的问题记录。

| 原核查问题 | 本轮修改结果 |
| --- | --- |
| 编排仅显示步骤 | 按顺序执行条件识别、资源/知识检索、指标计算、展示、申请入口和模板调用；子智能体共享任务上下文，记录逐节点输入输出并防止循环调用。 |
| 提示词未影响回答 | 增加规则回答模板，发布后控制实际输出；原提示词正文作为执行输入可追踪。没有接入任意自然语言提示词推理。 |
| 字段、字典和模板不联动 | 字段同义词与枚举编码/名称/值参与检索；AI 查询与显示开关生效；字段可选择枚举字典；模板按字段名应用合并。 |
| 元数据细节不完整 | 增加资源子类型、来源类型、字典项值、结构化表关系及图层数据源映射，保存时检查关联字段。 |
| 数据清洗、批量导入缺失 | 增加规范化、空白处理、重复段去除、清洗预览；支持每批 20 个本地文档，逐项显示结果并保留处理批次。 |
| 200KB 与 10000 字限制不一致 | 正文与导入统一为 UTF-8 200KB；超过 10000 字且符合字节限制的正文可保存。 |
| 切片与向量化过程缺失 | 可配置切片长度，建立本地字符二元特征向量，按相似度检索相关片段，保留来源与版本引用。 |
| 知识图谱只有文本 | 新增结构化实体、类型、关系，校验边端点，提供网络图预览和维护入口。 |
| 指标仅手填数字 | 新增示例 CSV 表取数、字段校验、区域/周期过滤、算术表达式与指标依赖；拒绝无权数据、循环依赖及除零。 |
| 无复合指标与趋势对比 | 新增年度耕地面积、保护目标和达标指数；可对比不同年度、不同区域，显示变化比例、数据来源及依赖版本。 |
| 无语料评测与回归 | 新增预期答案片段、资源集合、操作序列；运行发布版与草稿版对比，保存实际结果及失败原因；评测不消费测试样例本身。 |
| SQL 只做替换、无 API 调用 | SQL 对本地授权表执行只读 SELECT；API 模板执行本地资源检索，可在编排中调用；支持训练样例 JSONL 导出。 |
| 画像与长期记忆不完整 | 新增技能等级；保存多轮关键追问、条件、涉及资源/指标、来源任务及后续动作；手工摘要参与默认条件。 |
| 新会话不能接续任务 | 支持选择历史任务新建会话接续，或者启用记忆后提问“继续上次任务”；明确新条件优先，禁止接续他人会话。 |
| 申请离开对话 | 回答可直接打开本次结果的申请表单，提交后保留对话页面，沿用原审批及授权流程。 |
| 接口及反馈闭环不完整 | 新增 `/api/v1/agents/invoke`、契约与后台试调用；反馈可形成元数据或记忆改进草稿，经确认后应用。 |
| 统一权限不完整 | 增加知识、指标、智能体的可见性、部门及区域限制；SQL 和指标计算落实到示例数据行的区域范围，前台不下发原始指标配置值。 |

## 仍然明确保留的边界

1. 真正的大模型语义推理、任意自然语言到 SQL/API 的生成、模型微调训练尚未接入；当前是可执行规则、模板及评测流程。
2. 向量索引是本地字符特征；摘要是多轮信息的规则提取，不能等同于嵌入模型和大模型语义压缩。
3. 批量导入支持本地 TXT/Markdown，可配置来源；未连接在线文档、生产知识源或异步任务系统。
4. 图谱支持人工维护，未实现自动实体抽取；编排支持有序与嵌套调用，未实现复杂分支、循环及分布式调度。
5. 外部智能体、生产数据、GIS 算法、真实资源中心审批及统一身份仍需后续集成。

因此本轮已把主要核查缺口补为可操作、可验证的原型流程，但不据此宣称原始需求中的全部生产能力已经交付。

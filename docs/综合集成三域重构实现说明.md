# 综合集成三域重构实现说明

- 日期：2026-09-16
- 依据：[原始需求](../img/运营中心/综合集成.md)、[已确认的实现方案](综合集成原型重构实现方案.md)
- 状态：已实现，已切换本地 5190 原型服务。

## 1. 页面与功能

综合集成现在以“看成果、找资源、办本人任务”为主线，左侧只保留四个入口。

| 入口 | 地址 | 已完成内容 |
| --- | --- | --- |
| 一张图成果 | `/#/admin/integration-results` | 空间图层、工具箱、应用场景、成果使用概况；保留查询、定位、历史、查看与分析权限；返回时恢复场景、筛选、图层开关、透明度和视角，并重新读取授权 |
| 数字资源 | `/#/admin/integration-resources` | 搜索优先；六类数量可点击；按权限进入中心；最新与热门资源、个人搜索历史和聚合热词；资源详情、使用/申请、收藏、手册与来源中心维护入口；宣传内容下沉 |
| 个人工作台 | `/#/admin/integration-workbench` | 本人待办、常用应用、常用工具和消息直接呈现；指标点击进入服务端同口径列表；任务按来源、状态和标题筛选；消息按类型及未读筛选；收藏分组排序、刷新与免打扰配置 |
| 集成配置 | `/#/admin/integration-settings` | 四个内部分组：门户展示、系统接入、运行维护、权限与租户；仅平台管理员可进入 |

三个使用入口共用内部框架，公众门户保持独立。统一入口 `/#/admin/integration` 恢复本人上次可访问的使用页，默认个人工作台。使用页不会出现同步导入、编排、发布等管理操作；详情中的维护链接按权限显示。

## 2. 配置功能归属

- **门户展示**：展示设置、导航、Banner、宣传、动态、公告、展示分类；保留上传、草稿、预览、发布、停用、版本历史与恢复。
- **系统接入**：内部系统、国家节点、纵向交换、横向平台。内部系统详情包含基本信息、认证关联、待办接入、运行记录和实施进展；国家、纵向、横向对象可查看自身实施进展。
- **运行维护**：原运行总览、异常、使用监测。失败重试、批次错误、人工处置和状态核对仍然可达。
- **权限与租户**：成果查看/分析授权、查询范围策略、租户及成员管理；内部空间准入仍在既有身份管理维护。

视觉设置与空间查询策略分别保存、分别发布，发布一项不会带出另一项的未发布草稿。两者沿用原有设置主记录与历史快照。

租户管理从个人桌面移出。有权限成员可通过数字资源的“本级租户资源”进入原有局部隔离工作空间，继续行使已授予的资源或委派管理权限。

## 3. 服务端数据与权限

| 项目 | 实现边界 |
| --- | --- |
| 内部准入 | 用户记录新增 `internalAccess`；只迁移明确的内部演示身份和已有管理身份，不按“业务用户”角色批量放行公众账号；仅平台管理员可修改，变更进入原审计链路 |
| 成果权限 | 保留独立的查看/分析授权；撤回成果权限不影响已获准使用的个人工作台和数字资源 |
| 发布态资源门户 | `resourcePortal` 始终使用发布快照，按人群、部门、租户与有效期筛选；管理员使用页也不读草稿 |
| 本人工作数据 | `personalWorkbench` 与 `integration.workbench` 复用本人任务规则；外部任务按接收人，本地流程任务按原处理/委托规则；管理员工作台同样只看本人任务 |
| 统计口径 | 待办包括待办、在办、已挂起；已办包括已办、已办结；正常、逾期、预警只在未完成任务中互斥分类；列表与卡片共用服务端逻辑 |
| 成果使用摘要 | `resultUsage` 只聚合当前可见目录对象，不开放原始管理事件、批次或人员明细；需成果查看权限 |
| 管理数据 | 原管理接口继续校验平台管理员权限，不因进入内部框架而放宽；资源、收藏、系统等继续使用原主对象 ID |

任务提醒、公告弹窗、已读和免打扰仍沿用个人设置；地图缓存按用户分开，恢复时只启用本次接口确认有权访问的图层。

## 4. 地址与返回兼容

- 原 `front/integrated-portal`、`front/internal-home`、`front/integrated-workbench`、`front/integration-results` 替换跳转到对应内部页。
- 原 `admin/center-integration?tab=…` 定位到集成配置对应区域，来源系统和筛选参数保留。
- 搜索、类型、主题、部门、页码、工作列表与成果标签存入地址；刷新、返回可恢复。
- 从资源或成果进入原中心后，提供回到原使用页的站内入口；不接收任意外部返回目标。

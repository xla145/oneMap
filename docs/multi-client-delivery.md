## 可验证业务闭环

1. 后台新增内容，提交审核并发布；移动端同步后可查看已发布公示。
2. 后台给 `field` 分派核查任务；移动端填写坐标、照片和结论提交；后台核查通过后，移动端和驾驶舱刷新查看结果。
3. 移动端提交意见；后台受理、分派和回复；移动端办理记录可见状态及回复历史。
4. 业务端导入 Polygon 成果，执行基础质检再审查入库；项目空间分析结果可保存，并生成报告记录和下载文件。
5. 移动端完成首次联网加载后断网，提交记录进入 IndexedDB 队列；重连补传，操作 ID 防止重复提交。409 冲突保留在队列，需人工确认后重新填写或放弃。

## 数据与安全边界

- 四个新增端通过同源 API 共享数据；刷新后同步，驾驶舱每 30 秒刷新，不是实时推送。
- 服务端验证角色写权限、区域与外业任务归属；状态流转、必填项、照片限制和版本冲突不能仅靠页面绕过。
- 演示账号选择无需密码；服务仅监听 127.0.0.1，不能按生产服务部署。
- 地图使用项目已有 DataV 参考边界，规划与生态范围为演示几何；所有计算不作为审批依据。
- 成果质检只覆盖基础结构、闭合和坐标范围；前端另做自相交检查，不替代正式质量检查系统。
- 时间图按记录最后更新时间分桶，不能还原历史业务状态；部分专题共享基础指标，并非完整专题模型。
- 本机快照有效期 24 小时，未加密；生产敏感数据不可直接沿用此缓存策略。
- 原有门户未改动，尚未与新后台同步。

## 自动验证

先启动服务，然后执行：

```sh
npm test --prefix nmg-onemap-shared
```

测试使用本机 Chrome，配置在 `nmg-onemap-shared/playwright.config.js`。覆盖四端路由、页面宽度、地图 canvas、发布和核查流程、角色限制、409 冲突、操作幂等、空间分析下载和移动离线重载补传。截图与失败记录在 `nmg-onemap-shared/test-results/`。

测试会新增名称包含“回归”的演示业务数据，并保留用于查看流程，不会清空原有数据。GPS 权限与真实设备轨迹、PWA 安装入口、原生系统行为仍需真机验证。

本轮验证结果：8 项 Playwright 测试通过，包含成果上传到入库的界面操作、四端页面巡检及跨端业务/离线测试；JavaScript 语法和 Python 编译检查通过。桌面与 390px 窄屏已检查截图和横向溢出。依赖审计为 0 个已知漏洞（npm 官方源，本次安装时结果）。

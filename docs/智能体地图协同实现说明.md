# 智能体地图协同实现说明

> 当前状态：按用户要求已撤下智能助手地图协同界面，恢复对话方式。以下保留本轮实现与规划记录，暂不作为当前页面使用说明。


日期：2026-09-15。首期使用现有 Python、SQLite 和原生 JavaScript 实现，共用已有会话、权限和资产发布机制。

## 使用入口

打开 `/#/front/intelligence`，选择“耕地保护分析”进入工作台。资源检索、耕地分析和协同助手启用地图；政策助手保持文字问答。地图使用 OpenLayers 10.10.0，复用 `内蒙古一张图demo/` 的底图配置和行政区数据，原 demo 未修改。

桌面左侧对话、中央地图、下方结果，点击图斑打开详情。手机通过“对话 / 地图 / 结果”切换。支持行政区、单个图斑、矩形与多边形范围；矩形点击两个对角，多边形点击起点闭合，Escape 取消。平移和缩放不会改变分析范围。

示例：选择 2026 年，提问“统计包头市的耕地图斑面积”，返回 1 个图斑、128.6 公顷。全区为 3 个、400 公顷。点击结果定位，再点击“用此图斑提问”可继续追问；清除选区回到行政区范围。历史任务恢复会话与范围，消息中的“在地图中查看”恢复该轮结果快照。

## 数据与管理

智能体配置新增地图启停、已发布场景和资源范围；草稿发布后生效。查询同时核验智能体、场景、图层和用户权限，历史结果重新检查访问权限。会话保存空间条件、结果、来源版本与统计口径。地图范围统计与原有行政区指标分开展示。

主要实现：`prototype/backend/spatial.py` 负责空间筛选与权限复核；`frontend/intelligence-map.js` 负责会话地图联动；`frontend/map.js` 提供 OpenLayers 地图适配。

## 实现边界

- 数据为虚构的 2026 年示例，其他年份返回无数据；区域与所选范围冲突会提示重新选择。
- 完整包含的图斑可累加属性面积；部分相交只统计命中数量，绝不将整块面积当作交叠面积。几何为最多 100 个顶点、无孔洞的简单多边形。
- 暂未接入大模型、真实空间数据库、精确叠加面积、缓冲区或风险预测；不支持的分析会说明限制。
- 验证期间天地图瓦片返回 HTTP 418，已验证自动回退到 demo 本地行政区底图。在线影像恢复依赖原服务网络与授权。
- 行政区数据采用原 demo 坐标标注进行近似转换，不能用于精确业务测绘。

## 验证

92 项 Python 测试通过，包含空间几何、权限撤销、历史脱敏、年份与操作限制；工作台 Node 检查通过。使用独立 SQLite 数据库，经局域网地址运行 `check_intelligence_map_browser.py`，验证专题进入、图斑追问、时间筛选、框选、历史快照、手机切换和纯政策助手，无浏览器 JavaScript 错误。

# 运营中心首轮简化实施说明

日期：2026-09-17。依据：[运营中心 PRD](运营中心PRD-业务说明与简化建议.md)。

## 使用入口

原服务地址不变：`http://127.0.0.1:5190/#/admin/operations/overview`。刷新页面即可加载新界面。

管理员左侧运营中心收拢为：**工作台、数据归集、数据资产、运行监控、配置管理**。报送人仍从本人待办办理。

## 已完成的改动

- 工作台优先显示审核、整改、入库失败和未关闭告警，以及本人待办。业务介绍和历史统计默认折叠。
- 归集任务按报送人展开；报送详情直接串起材料审核、质检、整改复检、按标准建表、字段映射和入库。
- 新增数据批次入口，历史批次同样可以进入连续办理页面，不要求补造报送任务。
- 入库采用“目标字段—来源字段”下拉表格，同名字段自动预填。空映射或重复来源字段会提示，执行时仍由后端复核标准、数据、规则与整改状态。
- 审核、质量与入库结果分别显示；归集任务原“已完成”在列表明确为“报送审核已完成”。
- 资产详情收拢为基本信息、质量与更新、服务与共享、关联与历史四个标签；增加类型及技术目录筛选。
- 从资产登记服务时预选该资产。跨对象详情保留来源办理入口，批次异常可直接进入处理页。
- 运行监控以告警处理为默认页面，巡检记录、归集状态和服务调用置于局部导航。
- 标准、模板、来源、目录、数仓及告警规则集中到配置管理；专业台账及统一监控仍有入口。
- 原有页面地址、对象标识、数据、版本历史、权限及后端校验规则保留。更新前端资源版本以便刷新后生效。

## 第二轮：配置管理由入口页改为实际工作区

根据“只是放了一些菜单”的反馈，本轮替换原来的配置导航卡片：

- 默认显示已保存的配置，左侧选择或搜索，右侧直接编辑。数据标准、质检模板、检查规则、数据来源、资产目录、存储位置、告警规则共七类均可原地保存。
- 标准字段用可添加、移除的行编辑，配置字段标识、中文名、类型和必填；检查重复字段，无需填写 JSON。
- 质检模板通过复选框组合现有规则；标准和模板先保存草稿，再显式发布。编辑未保存时禁止直接发布旧草稿。
- 页面顶部根据当前数据展示报送标准、质检模板、存储位置和告警处置的准备情况。未发布或规则版本已失效的模板、外部登记的存储位置不计入可用数。
- “使用情况”展示引用当前配置的任务、批次、数据表或资产，支持进入相关记录；维护影响和最近操作记录在编辑区可查看。
- 修改规则后，引用旧规则快照的模板提示需要重新发布。新版本不会自动重写已绑定任务的历史快照。
- 外部数据库配置检查仍只检查登记信息，明确保留“待外部联调”，不发起远程连接。
- 原来源系统接入及专业报告入口保留在底部折叠区域，不再占据配置页面主体。

本轮未改后端业务规则，直接调用原有保存、发布和配置检查接口；也未写入正式演示库。

验证：后端 268 项回归通过；当前前端测试共 19 项通过（含新增的配置就绪判断和字段校验测试）。浏览器使用独立端口 5208、数据库 `/tmp/onemap-config-workspace-20260917.sqlite3`，验证标准新建发布及实际归集引用、模板发布与规则失效提示、其他配置保存、搜索、七类配置桌面/手机布局和非管理员权限。浏览器操作使用 DOM input/change/click 与 requestSubmit，持久化断言使用只读业务接口。
